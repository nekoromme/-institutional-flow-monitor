# 次の独立期間での検証条件

2026年9月10日。現段階は実行前の計画。2026年1〜3月の再評価を、別期間の成功に数えない。

## 検証する仮説

「早い時点での反復は、四半期全体の一度でも反復より、後の保有増加との関係を識別しやすい」を次の仮説にする。早い時点に固定すれば、答え合わせまでの時間と、異常に当たる機会の数を揃えられる。機関が四半期初めだけ買うという仮説ではなく、日々の監視は全期間続ける。

評価の主比較は四半期最初の20通常取引日。比較相手はその同じ20日で反復のない銘柄。補助として従来の四半期全期間を残す。20日は約1取引月という運用単位から固定し、18日・22日などを試して良い方へ寄せない。基準60日・95％位置・反復2／5は維持する。単純な異常の有無も同じ期間で併記する。

## 対象と情報の時点

- 次の候補期間は2026年4〜6月。当時の選定日は2026年4月1日。2026年3月末の保有報告を選定に使わない。
- まず既存の固定200候補から、4月1日より前に公開された2025年12月末の報告保有株数と同期期末の普通株発行数を照合する。20％以下を主対象とし、分母や株式種類を確認できないものは理由を残す。
- 年初の対象群をそのまま4月の低保有群と呼ばない。当時の上場・銘柄識別・併合後の株数単位も別に確認する。
- 新しい対象一覧と入力資料の識別情報を、4〜6月のシグナルと保有差を結合する前に保存する。今回の200候補自体が全米株の無作為標本ではない制約を残す。

## 答え合わせと比較

2026年3月末と6月末の公開報告株数差を、同じ株数単位で比較する。情報の締切は2026年9月1日より前。全報告合計と両期に観測された同じ運用者だけの合計を両方示す。報告が見つからない期をゼロとせず、品質上の保留件数も残す。

一銘柄を一票とし、同じ銘柄の連日通知で標本数を増やさない。第一に、旧条件と候補条件を同じ採点可能銘柄で比較する。全期間が欠けた銘柄も候補の20日だけ揃う場合は、その追加分を別の運用範囲比較にする。

最初の反復日、判定に使える情報の時点、後の保有書類公開日を記録する。四半期の保有差には通知前の売買も含まれるため、日付の差をそのまま機関買いを見抜いた先行日数とは認定しない。

## 採用判断

候補の報告増加割合だけが良くても即採用しない。比較群との差、通知対象の件数、保有増加した銘柄をどれほど拾えたか、発見までの時間、保有集計方法による変動を揃えて判断する。主対象で比較相手が残らない、件数が小さい、一銘柄の除外で結論が逆転する、集計方法で符号が逆転する場合は保留する。

一つの別四半期で良い結果が出ても最終認定はしない。次の未使用期間でも再現するか確かめる。閾値・期間・価格条件を同時に変更しない。反復が改善しない場合は、複雑な指標を足す前に単純な異常条件へ戻すことも候補にする。

## 実行前に残る資料
