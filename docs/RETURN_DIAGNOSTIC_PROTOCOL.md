# 初回の通知後損益診断：実行前の条件

2026年9月10日。[利益を主目的とする計画](PROFIT_FIRST_VALIDATION_PLAN.md)の最初の実行条件。新しい将来価格と通知の結合結果を見る前に保存する。

1. 対象は既存の固定54候補、通知期間は2026年1月1日〜3月31日。通知と反復の条件は変更せず、取得できる日足を2026年4月30日まで延長する。価格診断用に2025年12月15日以降を取得する。既存通知の元データと重なる部分の一致も確認する。
2. 通知日のニューヨーク日付が終わって30分後を、情報を使用可能とする仮定の時点に置く。次の通常取引開始時の日足始値を購入の参考価格とする。実際の過去の通知・確定時刻や、始値での注文成立は未確認。
3. 購入日を1日目として、5・10・20取引日目の通常取引終了時の日足終値を売却の参考価格にする。主結果は10日。各モデル・保有期間別に同一銘柄への保有中の追加購入を止め、売却日までの通知を再購入に使わない。1〜3月で開始した試行だけを採点する。
4. 株式分割・併合を補正した価格比を使い、正式資料との照合が不明な日を含む取引は不明にする。未取得・ゼロ・不正な値・重複・評価中の欠けた日は0損益にしない。予定の取引の評価が不明なら、その後の同じ銘柄の保有状態も不明として追加の成績計上を止める。
5. 主な費用仮定は買付額・売却額の各0.25％。各0、0.5、1％も同時に計算する。価格比をR、片道費用をcとして損益率は R×(1−c)/(1＋c)−1。費用は実測した売買価格差ではない。
6. 現金配当補正を含む提供元の日足も別に取得し、価格のみの結果との差を示す。これは提供元の補正による参考値で、実際の配当入金・再投資・税引後損益の照合を代替しない。主表の価格損益は配当を含まないと明記する。
7. 比較用の市場全体はSPYを使い、各試行と同じ購入日・売却日で比較する。業種・規模・売買の活発さまで揃った比較群は未完成なので、一般的な優位性の認定はしない。
8. 54候補全体と、既存の低保有群・相対的低保有群を別記する。各群の母数、通知不明、価格不明、重複による見送りを残す。平均、中央値、勝率、平均の勝ち負け、最悪例、最大逆行の参考値、一銘柄ずつ除いた影響、費用で利益が消える件数を示す。取引数は独立した標本数や資金全体の運用成績と同一視しない。
9. 10日試行では、通知前5取引日の上昇／非上昇、翌朝の価格上昇／非上昇、通知日終値が当日値幅の上半分／下半分、月別で結果を診断する。境界は0と値幅の半分に固定し、最も良い境界を探さない。翌朝の価格を見て始値購入を遡って選ぶ条件にはしない。
10. 反復を待つ診断では、単純な異常モデルの最初の通知が反復ではなく、次の4取引日以内に初めて反復になった場合に限り、それぞれ翌日に買った10日結果を比較する。将来反復した事例だけを後から選ぶ補助診断であり、最初の通知時点で選べる戦略や独立した取引標本とは扱わない。反復しなかった例を含む実際の両モデル全体の結果も必ず残す。
11. 執行の標本点検は、10日試行の各モデルについて低保有群の各銘柄最初の試行を全件、それ以外から日付・銘柄順で最初の5銘柄を固定して選ぶ。購入開始の1分と売却直前の1分が存在し、日足の参考価格と一致するか調べる。成立数量・気配・全試行の執行を保証する点検ではなく、この標本だけで数値を修正しない。

今回の結果は1〜3月の探索的な価格診断。条件を最適化した実売買戦略、配当込みの確定損益、資金制約を含む運用利回り、別期間で再現した優位性とは呼ばない。原価格と出来高は公開せず、派生した損益と件数・日付・入力のハッシュを保存する。
