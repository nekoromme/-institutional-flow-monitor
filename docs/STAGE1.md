# 第1段階の作業記録

状態：接続試験を実装済み。GitHub上での実測結果を確認中。

この段階は、価格・出来高・機関保有の資料が取得できる範囲と、残る難所を調べます。
モデルの作成や投資成績の検証は次の段階です。

## 実装済み

- 5銘柄の約3年の日足、20営業日の1分足、短い区間の約定・気配を明示的な配信区分で取得。
- 複数ページ、取得上限、時刻、重複、形式不整合、通常取引時間を検査。
- 秘密情報と生の市場データを公開しない診断出力。
- 米国証券取引委員会の会社・銘柄一覧、保有報告二期、発行済み株式数の取得試験。
- 未来の書類、オプションと普通株の混同、単一取引所への暗黙切替を防ぐ確認。

## 実行結果

合成データを使う15件の確認は成功。実アカウントの権限・取得件数は、実行結果の確認後にこの記録を更新します。

## 現段階では断定しないこと

- 無料アカウントの全米市場データ権限。
- 5銘柄以外も同じ品質で取得できること。
- 証券番号と銘柄コードの完全な過去対応表ができたこと。
- 全機関の保有率を復元できたこと。
- 異常出来高と機関流入、または将来利益との関係。
