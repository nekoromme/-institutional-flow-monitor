## 2. 見つかった重要な問題：分足がなくても売買は存在する

20営業日で、通常取引時間内の1分足がある割合には銘柄差がありました。通常日の9時30分以上16時未満の390分を基準にしています。

| 銘柄 | 存在した1分足 | 存在しない分 | 存在しない割合 |
| --- | ---: | ---: | ---: |
| AAPL | 7,800 / 7,800 | 0 | 0.00% |
| MU | 7,800 / 7,800 | 0 | 0.00% |
| ONTO | 6,640 / 7,800 | 1,160 | 14.87% |
| AAOI | 7,798 / 7,800 | 2 | 0.03% |
| FN | 7,553 / 7,800 | 247 | 3.17% |

存在しない区間から、ONTO・AAOI・FNを各2区間、合計6区間選び、同じ時刻の歩み値を追加取得しました。

- **6区間すべてで実際の約定を確認。売買がなかった区間ではありませんでした。**
- ONTOの2区間は各34件、AAOIの2区間は37件・76件の約定があり、すべて小口取引の条件が付いていました。
- FNの2区間にも27件・36件の約定がありました。小口取引だけでは説明できず、個別の集計条件は未分類です。

提供元は、価格の集計条件を満たさない取引だけの場合などに足を生成しないと説明しています。今回の標本は、その仕様が研究に影響し得ることを示しています。[Alpacaの集計規則](https://docs.alpaca.markets/us/docs/market-data-faq#how-are-bars-aggregated)

**採用する対応：分足のない区間を出来高0で埋めない。分足を足し合わせた値を、通常取引時間の完全な出来高だと決めつけない。**

6区間の確認から、欠けた全1,409分の原因や、失われた出来高の割合までは推定しません。また、16時ちょうどの終値を決める一括取引の扱いは別途必要です。390分の連続取引と、終値の一括取引を含む一日の出来高を区別します。

第2段階で比較する候補は、提供元の日足の出来高を一貫して使う方法と、約定の条件・終値の一括取引を整理して通常取引時間の出来高を作る方法です。日足の出来高には時間外取引が関係し得るため、通常取引時間だけの値とは見なしません。どちらを採用するかは、まだ決めていません。

## 3. 保有資料の実測と制約

GitHubの実行環境から、米国証券取引委員会の会社・銘柄一覧への要求は403（取得拒否）でした。市場データのキーの問題とは別です。

この作業環境では、通常の読み取り要求で次を取得できました。

| 項目 | 結果 |
| --- | --- |
| 会社名・銘柄コード・会社の識別番号 | 試験5銘柄を照合できた。証券番号はこの一覧に含まれていない |
| Berkshire Hathawayの2026年6月末の保有報告 | 2026年8月14日公表の正式書類を取得。89行を解析 |
| 同社の2026年3月末の保有報告 | 提出日などの情報は取得。保有一覧の取得は通信のタイムアウトで未完了。対象を絞った再試行も失敗 |
| 発行済み株式数 | 5銘柄すべてで公式提出資料の履歴を取得。基準日・公表日・株式種類を合わせた検証は未完了 |

6月末の報告では、Appleの普通株について会社名と株式種類が一致する行を抽出し、証券番号まで追えました。ただし、これは限定した照合候補で、銘柄変更を含む汎用的な対応表が完成した意味ではありません。

SECの履歴にある表示用フォルダ付きのリンクを、元の資料のリンクへ直す処理も追加しました。[取得できた保有一覧](https://www.sec.gov/Archives/edgar/data/1067983/000119312526352200/56757.xml)、[診断と再試行の記録](evidence/sec-probe-local-2026-09-10.json)

**残る作業は、取得の安定性、もう1期との照合、証券番号と銘柄コードの過去対応、訂正・複数運用者の重複整理です。** 一つの運用会社の報告や、掲載のない銘柄を使って全機関の保有率を計算する処理は作っていません。

## 4. 負荷と保存の判断

市場側の試験は追加確認込みで52回の通信、約9.55メガバイト、約31秒でした。再試行は0回です。GitHubの起動・準備時間はこの31秒に含みません。

20営業日・5銘柄の分足要求だけで約6.82メガバイトでした。同じ密度を仮定して300銘柄・252営業日に単純比例させると、応答データは約5.15ギガバイトです。時間外のレコードも含む小標本の概算で、銘柄の違い、圧縮、保存形式、保有資料、索引などは反映していません。

したがって、無料で取得できる範囲があることと、無計画な全件保存が軽いことは分けて考えます。初期研究は日足を基本候補にし、分足・歩み値・気配は必要な区間だけ取り出す構成を検討します。

保存先と保持期間は未決定です。現在の実行は生の市場データを保存・公開せず、診断情報だけを残します。継続研究用には、利用条件に合う非公開の保存先を第1B〜第2段階で決めます。

## 6. 次の最小工程

次は **第1B：保有資料の取得経路と照合を固める** です。

1. 取得できなかったもう1期の正式資料を、許可された通常の取得経路で確認する。
2. 個別取得と公式の一括データ取得について、実行環境・保存方法・手間を比較する。
3. 少数銘柄で二期の保有株数と発行済み株式数を、基準日・公表日・株式種類を揃えて照合する。
4. 必要な資料が安定して揃う見通しを確認してから、第2段階の対象選びと検証仕様を固定する。
