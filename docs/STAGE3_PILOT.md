# 出来高モデルの技術試行と、保有報告との対応表

2026年9月10日／コード0.4.0／volume-pilot-0.1

段階2の全完了を待たず、固定済みの計算が動くかだけを限定して点検する。低保有銘柄の認定、機関検出精度、投資成績の検証は未完了。判定結果を見る前に、この範囲と保留規則を固定する。

## 今回計算する範囲

- UAVS・QMCO・MU・ONTO・AAOIの指定5銘柄、2026年1月1日〜3月31日だけ。
- 対応する保有比較は2025年12月末→2026年3月末。四半期終了後の出来高を、この保有変化の答え合わせに混ぜない。
- 反復計算のため、1月最初の日より前の4営業日も判定する。4月以降と他の四半期の候補数・成績は出さない。
- 前段で準備した市場カレンダーを保持する。短縮日や欠損日も反復の5営業日から消さない。

これら5銘柄はユーザー指定の技術試験標本で、当時の規則で選んだ低保有銘柄群ではない。既に見た保有変化との対応表は探索用であり、未見期間での予測検証ではない。

## 計算は既定の二つだけ

1. 判定日を含めず、直前60回の通常の長さの営業日の出来高を、判定日の株数単位へ補正する。既存のデータ品質点検に通った窓のみ使う。
2. その60個を小さい順に並べた57番目が95%境界。同値は異常とせず、当日の出来高がこれを超えた場合のみ異常日とする。
3. 当日が異常日、かつ直近5営業日に異常日が2日以上なら反復候補。5日内に一つでも判定不明があれば反復も不明。

基準中央値に対する倍率も非公開の日別記録へ残すが、追加点にはしない。今回、しきい値の調整や銘柄別の最適化は行わない。

5%は過去の出来高分布上の位置であり、機関買いの確率ではない。将来も必ず全日の5%が異常になる意味でもない。

## 共同報告の未解決部分をどう扱うか

[参照の整理と確認優先順位](evidence/holdings-uncertainty-2026-09-10.json)を追加した。元の全件監査表と運用者別台帳から再生成できる。

| 参照 | 分かること | 今回の扱い |
| --- | --- | --- |
| 保有行の共同運用者番号 | その保有行に関連する相手の参照がある | 相手の特定と同じ証券の報告を確認する対象 |
| 表紙の別報告者 | その報告者が一部の保有を別途報告する関係がある | この銘柄とのつながりは未確認。全株数を重複扱いしない |
| Calamos二社のような双方の保有行 | 同じ銘柄を双方が報告し、原表にも同じ数字がある | 経済的に同じ保有かは別途確認。既存の二通りの計算を維持 |

13Fは共同運用する同じ保有の二重報告を避ける制度だが、表紙の参照だけで個別銘柄の二重計上を断定できない。[SECの記入要領](https://www.sec.gov/files/form13f.pdf)

点検の優先順位として、その問題に関係する運用者の報告株数を記録する。同じ運用者に参照が複数あっても一度だけ数える。これは、その株数全部が重複という意味でも、誤差の上限・下限でもない。相手側の欠けた報告株数は、この値では測れない。

| 期末 | UAVSの関連運用者の株数 | QMCOの関連運用者の株数 |
| --- | ---: | ---: |
| 2025年12月末 | 422,015 | 277,372 |
| 2026年3月末 | 1,144,989 | 268,095 |

UAVSの3月末の値には、Calamos二社の合計603,344株も含む。これをすべて合算から差し引く処理はしない。BlackRockやNorthern Trustの表紙参照と、Virtu・T. Rowe Priceの保有行参照を区別して次の調査順を判断できるようにした。

## 答え合わせを保留する規則

現時点では全5銘柄の `institutional_flow_label` と `low_ownership_at_signal` を不明のまま保持し、精度集計の対象から除外する。未解決参照が0件でも、取得範囲・省略・株式種類などが確認できるまで自動認定しない。

対応表に載せるのは、異常日数、反復候補日数、判定不明の日数、既存の点検用報告株数の差。連続した候補を別々の独立した的中事例として数えない。答え合わせの単位は銘柄×四半期とする。

報告株数が増えていても、その期に機関が市場で買ったという確定ラベルを付けない。UAVSの発行済み株数増加とCalamosの感度計算、QMCOの期末と一致しない分母は[前回の点検](STAGE2_REVIEW.md)を併読する。

今回は現在取得する過去データを使う。当時配信された版の市場データと、実際の通知到着時刻は復元できていない。後日の訂正情報の影響や実際に何日前に通知できたかは未検証なので、先行日数や売買リターンを作らない。
