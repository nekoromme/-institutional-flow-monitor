# 要因検証の固定条件

2026年9月10日。今回の検証は条件の最適化ではなく、前回の結果を弱くしている測定・集約・標本の問題を切り分ける。元の54銘柄・低保有の6銘柄・下位3分の1の18銘柄と、モデルの条件は維持する。

新しい実行結果を見る前に、次の比較を固定する。

1. 前回四半期の判定が揃った49銘柄に限り、1月末・2月末・3月末の各時点までに異常・反復が一度以上あった割合と、報告保有増加との対応を比較する。期間の長さで条件がどれほど緩くなるかを測る。これは別四半期での検証ではない。
2. 同じ49銘柄の異常日・その他の日について、前営業日終値からの上昇・下落・横ばいを数える。下落を機関売りとは呼ばず、出来高が増えたことだけで買い方向を想定できるかを点検する。価格条件はモデルへ加えない。
3. 報告合計と両期に観測された同じ運用者の合計で、増減の判定が変わる件数を確認する。どちらも完全な機関売買の正解表にはしない。
4. 各比較から一銘柄ずつ除いたとき、反復の有無による差がどれほど変わるかを確認する。信頼区間や因果効果とは解釈しない。
5. SMSI・GAME・KAPAの補正前後の比が期間全体で一定か、価格と出来高が逆向きに同じ倍率で変わっているかを検査する。両方を別々に採点した際の一致も確認する。公式な株数変更の確定や保留解除は行わない。
6. LSHのゼロ出来高を、実際に取引がなかった正しい0だと仮定した場合だけ再計算する。取得できない日を0で埋めない。元のモデルと本番採否には反映せず、仮定付きの感度検証とする。

要因5・6の結果を加えた見かけの成績で、今回のモデルの優位性を主張しない。影響が大きい要因と未確認の要因を区別し、次の修正・別期間での検証の順序に使う。現行のモデルを変えた場合は別の版として評価する。
