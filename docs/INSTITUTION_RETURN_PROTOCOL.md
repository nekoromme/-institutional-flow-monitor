# 機関保有の増加と通知後利益：照合前の検証条件

2026年9月10日。既存の保有増減と取引損益を結合する前に、この分析の条件を記録する。両方の資料は既に別々に検証され、損益も閲覧済みなので、新しい独立標本の事前登録ではない。

## 問いと、測れる範囲

「実際に機関が買った通知ほど、その後の取引で利益が出るか」が問い。ただし日単位の買い手の身元は観測していない。その代わりに、2025年12月末から2026年3月末への**報告保有株数の増加**と、既存の通知後損益の関連を調べる。

- 主な代理情報は `observed_reported_increase`。比較群の false は「報告株数が増加しなかった」であり、「機関が買っていない」ではない。
- 感度点検は、両期とも保有を報告した同じ運用者に限る `matched_manager_increase`。新たに入った運用者を除く別の尺度なので、結果を良くするために主尺度と交換しない。
- 欠損は不明として別計上し、非増加へ入れない。厳格な保有品質の条件を満たす銘柄数も必ず示す。
- 実際の売買主体、購入日、情報優位、運用者別の能力を識別した検証とは呼ばない。保有割合が低いことと、保有が増加したことを区別する。

## 固定する入力と比較

主モデルは既存の価格方向追加版 `repeated_up`。単純版と反復版は感度点検とし、重複する取引をモデル間で合算しない。翌営業日始値で購入し、購入日を含む10取引日目の終値で売却、片道0.25％の費用を仮定した既存の価格損益を変更せず使う。配当・実約定・資金制約は未反映。

| 区分 | 対象 | 解釈 |
|---|---|---|
| 同じ四半期の事後的な関連 | 2026年1〜3月の通知 | 後から分かる四半期保有増減との関連。売買時に利用できた説明変数ではない。3月末通知の出口が4月になることもある |
| 公表後の関連 | 2026年6月2〜30日の通知 | 6月1日時点までの提出で作った保有情報を使える期間。新たに見ていない成績ではなく、既存の取引列の一部分。6月に戦略を新規開始した再計算ではない |

年初に固定した54候補全体が主対象。年初の報告保有20％以下の6候補を副対象として別掲する。通知のない銘柄は、機関が不在・取引損益0とは扱わない。

## 集計と不確かさ

1. 同一銘柄の取引損益を先に平均し、各銘柄を同じ重みで比較する。同じ四半期の保有ラベルを、複数取引分の独立した証拠として水増ししない。
2. 主な差は、増加群の銘柄平均損益から非増加群の銘柄平均損益を引いた値。銘柄平均勝率、SPYとの差も併記する。取引ごとの平均・中央値・勝率は補助値。
3. 0／1の保有増加と銘柄平均損益との相関係数も示す。両群や損益の変動がなければ不明。
4. 両群に5銘柄以上ある場合だけ、群内で銘柄を復元抽出する10,000回のブートストラップによる95％区間を計算する。乱数は固定。これは日付・業種の共通変動やラベルの誤りを解決する区間ではない。因果効果・確定的な優位性の判定に使わない。
5. 一つずつ銘柄を除いた差の範囲を示す。副対象の少数例で有意性や一般的な相関を主張しない。

## 判断方針

保有増加条件を通知へ追加するかは、利益・勝率の関連が時点と尺度をまたいで整合するかを調べた後に判断する。今回の記述的照合だけで本番の絞り込み条件を採用しない。「増加群が良くない」という結果も、機関の情報能力がないことの証明にしない。
