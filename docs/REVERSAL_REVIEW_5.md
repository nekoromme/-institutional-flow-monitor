# 反発・続落の原因追求と連続試行5

2026-09-11。条件ごとの確認を挟まず、原因診断→仮説の固定→再検証を3サイクル実行し、5つの追加戦略案を評価した。2023/2024年は既に見た探索期間。2025専用データは開いていない。

## 共通条件

親は前回の通知日下落シグナル。直近5日直前終値から日中高値が5%超上がらない、下落幅制限なし、事前の静けさ、異常出来高の反復、通知日終値が前日より低い。既知14銘柄除外・年別の母集団・翌日始値購入・10営業日目終値売却・費用片道0.25%を維持した。各案で重複保有を避けて売買予定を組み直した。平均は1取引あたりで、資産全体の利回りではない。

## 第1サイクル：説明しやすい仮説を反証

日中の安値から戻れば売りを受け止めた可能性がある、という案は2023年で悪化。2024年の9件だけの好結果で採用しない。長期下落を避ける案も両年で悪化した。

親の取引を翌朝の上窓/非上窓で分けた平均は、2023年＋2.82%／−2.32%、2024年−2.26%／＋3.13%と逆転。翌朝の値動きによる購入条件は追加しなかった。

出来高の反復だけを外した、同じ下落条件の対照は940件−1.14%／640件−0.74%。出来高反復ありは約1.10／1.28ポイント上回った。購入日と銘柄構成も変わるため、出来高の因果効果を測った結果とは言えないが、出来高の情報を捨てる根拠はなかった。

## 第2サイクル：売買量の山と反発余地

出来高情報を残し、「異常出来高が反復する期間の中でも量の山を越えてから拾う」を追加。期間は既存5日窓を当日と直前4日に分けた。出来高の減少自体は売り数量の減少を証明しない。

長期下落回避が両年で悪化したため、逆に過去60日中央値より下での反発余地を拾う案を追加した。この判断は初回の結果を見た後の探索だと明記し、親取引の良かった部分の集計ではなく売買予定を作り直した。両案とも平均は改善したが、強い利益の再現性は示せなかった。

| 条件 | 最大利益1件除外後 2023／2024 | 費用片道0.5% 2023／2024 |

| 親 | −0.54%／−0.25% | −0.53%／＋0.04% |
| 出来高減衰 | −0.78%／−0.18% | −0.44%／＋0.17% |

60日中央値未満の案は2024年には最大利益1件除外後もプラスだが、2023年はマイナス。銘柄ごとの平均を同じ重みにしても2023年−0.20%。出来高減衰案は2024年28件で、事前最低件数30にも不足する。

親取引の損失は2023年36件、2024年30件。そのうち16／18件は保有途中の終値では費用差引後プラスになっていた。14／8件は日中高値でのみプラス、5／2件は日中高値でも費用を回収せず、1／2件は最終価格の上昇が費用で消えた。途中最高値で確実に売れたとは扱わない。

## 判断と次の研究

今回の5案はいずれも、両年30件以上・平均正・最大利益1件除外後正・親および同じ追加条件の出来高なし対照より平均改善、という最低基準を満たさない。本番条件は変更しない。累積戦略案は10＋5＝15。今回の対照は6本。5日保有と20日保有の参考比較も試行記録に残す。

残す仮説は「周囲が上向く中で、異常出来高を伴って売られる個別銘柄の反発」。証明済みの優位性とは呼ばない。次に切り分けるべきは、負けが特定の銘柄・業種・企業イベントへ集中しているか、約定と気配から見た売り主導の強さが価格だけの分類に情報を足すか。前半除外や価格の閾値探しで帳尻を合わせない。
