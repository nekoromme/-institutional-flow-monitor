# 第4段階：通知後の価格損益と失敗原因

2026年9月10日。固定54候補・2026年1〜3月の通知を、4月末までの実価格で追跡した。主目的を利益へ移した後の初回診断である。

**現行の反復版は平均がプラスだったが、費用と少数の大当たりへの依存が残り、購入通知としての優位性はまだ認定できない。** 反復に価格方向を一つ加える案を次の比較候補にする。実際に約定した成績ではない。

## 固定した計算と、評価できた範囲

[実行前の条件](RETURN_DIAGNOSTIC_PROTOCOL.md)をコミット `bfb90d91173d88dfe33459a09f95dea3db1e56ef` で保存してから取得・計算した。通知条件は直前60通常営業日の出来高、既存の95％位置の境界、反復2／5のまま。購入は通知翌営業日の日足始値、売却は購入日を1日目とする10取引日目の日足終値を参考にした。

買付額・売却額の各0.25％を費用として引く。米ドル建て、個人の税引前、配当を除く価格損益。同額の1取引ごとの平均であり、元本全体の運用利回りではない。保有中と売却日の同一銘柄の通知では追加購入しない。

54候補は削除していない。1〜3月61営業日の通知判定は52銘柄で完全、LSHは60日、COMMは53日が不明。GAMEには異常通知がなかった。異常239銘柄日のうち保有期間の重複133件を見送り、106回の価格評価になった。反復112銘柄日は58件を見送り54回。発生した予定取引の10日価格評価には不明0件だったが、**通知が不明の113銘柄日を成功・異常なしとは数えていない。**

今回の再取得と以前の入力の重複部分に変更はなく、54銘柄すべての判定ハッシュも前回と一致した。日足は補正前・分割補正・分割配当補正の各5,091本を取得。全ページ取得済み。COMMは追跡用の94営業日のうち20日、ASGNは89日しかなく、その日を要する評価は行えない。今回の予定保有期間には該当しなかった。新しい銘柄コードへの無断接続はしていない。

## 何が利益を弱くしているか

### 1. 費用に対する余裕が小さい

| 買い・売りそれぞれの費用 | 異常のみの平均 | 反復の平均 |
|---|---:|---:|
| 0％ | ＋0.15％ | ＋1.26％ |
| 0.25％・主条件 | −0.35％ | ＋0.76％ |
| 0.5％ | −0.85％ | ＋0.25％ |
| 1％ | −1.84％ | −0.74％ |

これは費用の実測ではない。異常のみは費用前からほぼ横ばい。反復も売買価格差や価格のずれ次第で平均利益が消える。勝ちが負けに変わる件数は主条件で異常0件・反復1件だが、すべての取引の利益幅が削られるため、勝率だけでは問題が見えない。

### 2. 大当たりと時期への依存がある

全体で最大の当たり1件を除いた平均は、異常のみ−1.59％、反復−0.18％。銘柄を一つずつ除いた平均の範囲も異常−0.97〜＋0.02％、反復−0.06〜＋1.34％で、符号が安定していない。この範囲は統計的な信頼区間ではない。銘柄ごとの平均を同じ重みで平均すると−1.26％／＋0.33％だった。

| 通知月 | 異常のみ・件数と平均 | 反復・件数と平均 |
|---|---:|---:|
| 1月 | 26件・＋2.73％ | 11件・＋5.74％ |
| 2月 | 42件・−1.40％ | 26件・−1.18％ |
| 3月 | 38件・−1.30％ | 17件・＋0.50％ |

同じ購入日と売却日のSPYとの差は、平均で異常＋0.88ポイント、反復＋1.78ポイント。対応するSPY自体の平均は−1.23％／−1.02％で、今回の結果を単なる市場上昇だけでは説明できない。ただし業種・規模・非通知銘柄を揃えた比較がなく、銘柄選択の付加価値は未確定。

### 3. 反復には選別効果と待つ不利益の両方がある

後に4営業日以内に反復した49例に限ると、最初の異常の翌日に買った平均は＋3.05％、反復の翌日に買った平均は＋1.39％。待った側が平均1.66ポイント低かった。

一方、反復しなかった例も含む両モデル全体では反復版の方が良かった。したがって「待つと遅いから反復を撤廃」は支持しない。49例の比較は**将来の反復で対象を選んだ補助診断**で、最初の異常時に選べる戦略ではない。各購入から10日なので売却日もずれ、差のすべてを買付けの遅れだけには帰せない。重なる反実仮想の取引も含み、49件の独立した検証ではない。

### 4. 出来高だけでは価格の方向を区別できない

固定した境界で既存の反復取引を分けると、通知前5取引日の終値変化がプラスの25件は平均＋2.36％、勝率64.0％。ゼロ以下の29件は平均−0.62％、勝率41.4％だった。上昇側は最大の当たりを除いても平均＋0.62％だが、最悪−29.89％は残る。

これを根拠に、**反復に「通知時点で5取引日前より終値が高い」を一つ加える案**を次の比較候補にする。大量の売買だけを買いと読み替えず、既に判明している価格方向を確認するためである。5日は今回の診断前に固定した期間、境界0は上昇／非上昇という意味で、最高成績の数字を探索して決めてはいない。それでも結果を見て選んだ仮説なので、別期間での確認が必要。

上記25件は既存取引の内訳であり、新版のバックテストではない。条件で見送ると保有状態と次の購入候補も変わるため、新版では予定購入から再計算する。LAWの＋50.27％の反復取引など、下落からの反発を逃す不利益もある。

通知日の終値が値幅の上半分にある条件は、反復で＋0.95％／下半分＋0.58％、異常のみでは上半分−1.06％／下半分＋0.31％と一貫しなかった。今回の追加候補にはしない。翌朝の上昇側は良かったが、その始値を見てから同じ始値で購入できたとする先読みを避け、まず診断に留める。

## 期間・価格・配当について残る限界

補助として固定した5・20取引日もすべて計算した。

| 保有期間 | 異常のみ・件数／平均 | 反復・件数／平均 |
|---|---:|---:|
| 5日 | 134／＋0.50％ | 61／＋2.18％ |
| 10日・主結果 | 106／−0.35％ | 54／＋0.76％ |
| 20日 | 83／−0.16％ | 47／＋4.66％ |

保有期間が変わると重複による見送りも変わり、同じ取引の出口だけの比較ではない。20日の数字が良くても、主条件を後から20日へ変更しない。

事前に選んだ17取引で、開始の1分と終了直前の1分を点検した。開始17件は日足始値と15件一致・2件不一致。終了17件は5件一致・10件不一致・分足なし2件。引けの一括売買とその直前の分足終値は異なり得るので、不一致だけで約定不能とは判断しない。一致しても必要株数で売買できた証拠にはならない。次は価格の時刻、数量、気配を確認する。

日足と分足は、取引に付く条件によって集計規則が異なる。日足の始値・終値を特定時刻の実行可能な注文価格と同一視しない。[Alpacaの公式集計仕様](https://docs.alpaca.markets/us/docs/market-data-faq#how-are-bars-aggregated)。注文時の市場価格も保証されない。[Investor.govの注文と成立価格の説明](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders)。

分割と配当を補正した日足も取得したが、現在の「同じ日の四つの価格が共通倍率で変わる」という照合を通る組は10日で66／106件、35／54件だけだった。通った組では価格損益との差がなかった。残り40件・19件について配当効果なしとは言えず、補正方式の仕様と実際の現金配当を追加確認する。異なる母数の配当参考平均と全体平均を比較して配当効果とはしない。今回は明示どおり価格のみの成績である。

今回採用したのは損益評価の追加と、追跡用の営業日検査の修正。初回実行は旧試行の3月末限定の検査が4月を拒否して停止した。新しい価格の取得・損益計算に進む前の停止で、追跡用の範囲検査を分けて解消した。予測条件は変えていない。

次は[別期間の比較条件](NEXT_RETURN_VALIDATION_PLAN.md)で、現行2モデルと価格方向を加えた1モデルを比較する。4月は既に1〜3月通知の追跡に使ったため、次の通知期間を5〜6月へずらす。執行価格・費用の確認を併行し、合理的な仮説でも再現しなければ採用しない。
