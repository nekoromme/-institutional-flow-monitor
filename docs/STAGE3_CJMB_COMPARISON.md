# CJMBの二期比較：除外された報告を確認すると、増減の向きが変わった

2026年9月10日／コード0.5.2／cjmb-comparison-0.1

**CJMBの公開保有報告を比較できた。原表の確認後の合計は、2025年12月末の732,311株から2026年3月末の600,892株へ、131,419株減少した。** これは公開報告に記載された株数の比較であり、全機関がその株数を売り越したという認定ではない。

今回の重要な修正は、12月末の比較元から外れていたCreative Planningの205,693株を、原表の全行照合を根拠に集計へ戻したこと。確認前は74,274株の増加に見えていた。欠損・保留の扱いだけで増減の向きが逆転する実例になった。

## 比較期間と、情報を使える時点

- 対象選びの基準日：2026年1月1日。この時点までに公表された情報による確認結果を固定。
- 比較する保有期末：2025年12月31日と2026年3月31日。
- 答え合わせに使う報告の締切：2026年6月1日より前。

CJMBを今回の最初の比較対象にしたのは、前段階の確認結果による。今回の増減を見て対象を選び直していない。

12月末の発行済み株数を示す年次報告書は2026年3月31日提出、3月末の四半期報告書は5月15日提出だった。これらを2026年初の対象選びや出来高判定に渡さない。後の原書類を読むための締切は呼び出し時に明示し、既存の対象選定の締切は維持した。

## 確認後の数値

| --- | ---: | ---: |
| 公開保有報告の合計株数 | 732,311 | 600,892 |
| 正の株数が集計に入った運用者数 | 12 | 12 |
| 普通株の発行済み株数 | 4,858,663 | 5,646,118 |
| 報告合計÷発行済み株数 | 15.07% | 10.64% |

発行済み株数は787,455株、約16.21％増えた。報告合計の割合は約4.43パーセントポイント低下している。**現在の機関保有率として使う表ではない。** 各期末の同じ種類の普通株について作った、公開保有報告による比較用の指標である。

決算書の貸借対照表と株主資本の増減表を照合した。期首4,858,663株に、株式発行契約による発行768,705株と株式報酬の権利確定18,750株を加えると、期末5,646,118株になる。この期間の比較に使う株数の単位を確認し、過去の上場前の株式併合を今回の期間に重ねて適用していない。[年次報告書](https://www.sec.gov/Archives/edgar/data/2032545/0001493152-26-014292.txt)、[四半期報告書](https://www.sec.gov/Archives/edgar/data/2032545/0001493152-26-023708.txt)

両期の公式対象証券一覧でも、同じ証券番号131100109・普通株であることを確認した。

## Creative Planningの原表を全行確認

12月末の報告は表紙に4,596行と記載されていたが、一括データは4,593行だった。そのため、既存の処理では利用を保留していた。

原提出書類を取得した結果、原表そのものも4,593行だった。一括データと全行を、同じ行の出現回数も含めて比較し、完全一致を確認。記載された金額の合計139,705,144,107ドルも表紙の合計と一致した。CJMBの205,693株は、その確認済みの原表に含まれている。[Creative Planningの原提出書類](https://www.sec.gov/Archives/edgar/data/1540235/0001540235-26-000002.txt)

| 12月末の集計方法 | 12月末の合計 | 3月末との差 |
| --- | ---: | ---: |
| 件数不一致で報告を除外した確認前 | 526,618株 | ＋74,274株 |
| 原表を照合して集計へ戻した確認後 | 732,311株 | −131,419株 |

表紙の件数が違うという元の警告は消していない。確認した原書類・一括データ・提出番号・期末・対象範囲の指紋が一致する場合だけ、利用できるという別の判定を付けた。同じ運用会社の別の報告へ、この確認を自動で流用しない。

原表全体には同一内容の重複行が1件あったが、CJMBの保有行の重複ではない。原表の内容を勝手に書き換えたり、全証券の実際の保有が正しいと認定したりしていない。

## 増減を「新規参入・売却」と呼ばずに分解

| 報告への現れ方 | 合計株数の差への寄与 |
| --- | ---: |
| 両期に株数が集計された運用者 | ＋24,101株 |
| 12月末だけに集計された運用者 | −217,698株 |
| 3月末だけに集計された運用者 | ＋62,178株 |
| 合計 | −131,419株 |

両期に報告のある運用者だけなら増加している一方、全体の報告合計は減っている。片方の期に行がない理由には、保有の変化以外に報告の省略や報告主体の変更などもあり得る。片期だけの運用者について実際の保有ゼロや全売却とは表示せず、未観測の値を残した。

このため、報告合計の減少をそのまま「機関流出の正解ラベル」にする処理は追加していない。

## 残る不確かさと訂正の追跡

DRWの原表1,204行も一括データと完全一致した。ただし、CJMBの行が参照する運用者欄には会社番号や保有報告用の番号がなく、名前と別種の登録番号だけがある。提出者と同じ名前でも、それだけで参照先を確定していない。参照先不明1件の警告は維持した。[DRWの原提出書類](https://www.sec.gov/Archives/edgar/data/1481986/0001481986-26-000001.txt)

機密欄が不明な運用者も、12月末に2件、3月末に2件残る。公開保有報告は全機関・全保有を網羅するものではない。今回の数字は集計対象に入った公開報告の変化として評価する。

12月末の報告について、3月1日より前に提出された版と6月1日より前に提出された版も比較した。Morgan Stanleyが5月27日に訂正を提出していたが、CJMBの12株を含む行の内容は変わらず、提出番号などだけが変わっていた。合計株数は両時点とも732,311株だった。「合計が同じ」と「元の提出書類が同じ」を区別して記録している。
