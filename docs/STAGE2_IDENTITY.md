# 確認候補200件の銘柄照合と、原書類による点検

2026年9月10日／コード0.4.2／historical-identity-0.1・identity-sources-0.1

**200件のうち187件で照会先の会社候補を絞り、固定順の先頭20件を原書類で点検した。そのうち17件について、証券番号・発行会社・書類表紙の銘柄コードを対応づけた。** 会社名の類似だけで証券の同一性を認定していない。

当初の200件は[前回の固定一覧](STAGE2_COHORT.md)を維持。株価や将来の保有変化を見て入れ替えていない。モデルの判定条件も変更していない。

| 確認 | 結果 |

| 元の確認候補 | 200件 |
| 2025年の提出者名から照会先候補を一つに絞れたもの | 187件 |

各行は別の確認項目で、足し合わせない。187件は同一証券の確認完了数ではない。普通株の廃止届11社には先頭20件以外の照会先も含み、それらの証券番号との結び付きは未確認のものがある。

## 現在の銘柄一覧から逆算しない

2025年の四半期別の提出書類索引を4本取得し、2026年1月1日より前の提出だけを使った。SECの索引には、提出者名、固有の提出者番号、書類種別、公表日、原書類の場所が載っている。[SECの索引の説明](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)

省略された会社名を展開して照会先を探すが、複数候補が残れば自動で一社を選ばない。例えば、似た名称の上場会社と子会社、投資会社と運用会社を取り違える可能性がある。

この索引も現在取得した2025年分の再構成データ。SECは受理後の訂正・削除を四半期索引へ反映するため、当時ダウンロードした版と完全一致するとは限らない。取得した4本の内容の指紋を保存し、変わった場合は自動で上書きしない。[索引の訂正に関する公式説明](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)

## 同じ証券だと確認する方法

原書類の「Schedule 13D／13G」は一定の大口保有に関する報告。今回、この資料から保有率を足し上げてはいない。**証券番号と、その証券の発行会社番号の組**を照合するために使った。

報告した投資家の番号と、株式を発行した会社の番号は別。発行会社の欄を明示的に読んで照合する。次に、その会社が2025年中に提出した決算書の表紙から、普通株の種類・銘柄コード・登録市場を同じ文脈で取り出した。

## 廃止届があっても、普通株が対象とは限らない

照会先候補187社のうち、登録の廃止・終了に関係する書類が索引にあったのは19社。そのうち17社について、最新のForm 25という登録廃止の届出を読んだ。

- 11社では対象の記載が普通株だった。監視対象への採用前に、その効力・その後の再登録などを確認する。
- 4社では普通株以外が対象だった。
- 2社は今回の構造化された書式では読めず、原書類の確認を保留した。

例えばKraft Heinzの届出は2025年償還の変動金利社債が対象だった。これだけでKHCの普通株を上場廃止扱いにしてはいけない。[Kraft Heinzの原届出](https://www.sec.gov/Archives/edgar/data/1637459/0001354457-25-000390.txt)

ほかに、新株を買う権利や優先株に関係する届出もあった。単に書類名がForm 25という理由で普通株を消す処理を避けた。

今回読んだのは各照会先の最新届出。さらに古い届出が1件残る。届出が見つからなかったことだけで継続上場を保証せず、提出日から一律の日数を足して廃止日を作る処理もしない。

## 原書類の取得・読み取りも修正した

- 同じ大口保有報告でも、13Dと13Gでは発行会社番号・証券番号の項目名の大文字表記が異なる。両書式を区別して読み、項目の欠落を「証券が不一致」と誤表示しない。
- 決算書に普通株と社債など複数の証券があれば、別の文脈の銘柄コードを混ぜない。普通株が複数種類あり対応が曖昧なら保留する。
- 原書類の提出番号、種別、提出日、受理時刻を索引と照合。2026年初の時点を越える資料は使わない。
- 添付資料を含む全文が24MBを超えた3件は、原本文と原ヘッダーを個別に取得して確認した。対象提出番号と日付を先に照合しており、現在の銘柄コードの値は使わない。
- 最大3接続、接続ごとの間隔・時間・件数・容量を制限して取得する。完了・失敗・途中経過を保存し、取得済みの書類を繰り返しダウンロードしない。

51件の全文と、容量超過した3件の本文・ヘッダーを取得した。現段階では、銘柄ごとに原資料のURL・内容の指紋・確認結果を残し、再現できるようにしている。
