# 実験台帳：良かった案も失敗した案も残す

更新：2026年9月10日。目的は通知後の費用と下落リスクに見合う利益。機関の買いであることは必須条件にしない。原則として原因の仮説を一つ決め、比較条件を保存し、実装・実測・採否までを一単位として進める。

| 試行 | 理由・変更 | 結果 | 判断 |
|---|---|---|---|
| 出来高のみ→反復 | 単発の異常を除き、続く買付けを拾えるか | 1〜3月の10日平均−0.35％→＋0.76％、5〜6月＋0.18％→＋3.39％。前の保有報告との整合性だけでは付加価値は未確認だった | 価格損益の比較相手として維持。利益が出ることと機関を識別したことは分ける |
| 反復→反復＋価格方向 | 大きな売買だけを買いと誤認せず、通知までの5日間の価格が上向くか確認 | 1〜3月の取引予定から再計算した新版は27件・＋2.10％。固定後の5〜6月は30件・＋5.35％、旧反復44件・＋3.39％。費用片道1％、最大当たり除外でもプラス | 追加検証の優先候補。本番採用は保留。平均の負けが少し悪化、低保有群の新版は1件の損失、実行価格と配当は未解決 |
| 反復を待たず早く買う | 待機による利益の取り逃しを減らせるか | 後に反復した49例だけでは早い購入が平均1.66ポイント良いが、反復しない例を含む全体では単純版が悪い | 反復撤廃は採用しない。将来の反復で選別した成績を実行可能な戦略と扱わない |
| 当日終値の値幅内位置 | 売りが強い日を除けるか | 1〜3月の既存取引の固定した上半分／下半分の比較で、単純版と反復版に一貫した改善なし | 現時点の追加候補にしない。別条件との組合せ探索へ拡大しない |
| 低保有だけに絞る | 注目される前の初動へ近づけるか | 年初20％以下群の反復は1〜3月3勝だったが5〜6月は4件・−0.26％、新版は1件・−8.93％ | 絞り込みの有効性は未確認。全体の好成績で低保有群の失敗を覆わない |
| 価格の品質点検 | 分足の欠け・日足の違いを損益の誤認につなげない | 開始不一致2例の日足価格の約定を確認、終了直前の分足なし2例に引けの約定を確認 | 無取引・売買不能への短絡は棄却。気配の価格差と数量の検証は継続 |
| 機関保有の増加と通知後利益 | 大口への追随という仮説に、保有増加が追加の判断材料になるか。3モデル・2期間・2尺度で照合 | 主モデルの銘柄平均損益との相関は1〜3月−0.054、公表後＋0.028。損益差の区間は0をまたぎ、同じ運用者だけの尺度でも安定せず。保有ラベルの厳格な品質合格は0／54 | 保有増加を必須・加点条件にする案は現時点で採用しない。真の機関買いと利益が無関係と証明したものではなく、背景説明の補助情報として維持 |

以上の損益は配当を含まない価格参考値、主条件は翌営業日購入・10取引日保有・売買それぞれ0.25％の費用。統計的に確定した優位性や資金全体の運用利回りではない。

次の優先試行は、価格方向だけの比較相手を加え、出来高・反復の追加価値を確認すること。次にコード変更・配当・数量と資金制約を点検する。新しい試行では仮説、使った期間、試した条件の数、候補数と不明数、利益・損失・費用、採否の理由を追記する。成績を見た期間を未検証へ戻さず、失敗した案を無かったことにしない。
