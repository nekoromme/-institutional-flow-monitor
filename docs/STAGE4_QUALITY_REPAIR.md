# 品質修正を採用し、過剰最適化と区別した判断

2026年9月10日／コード0.6.4／ロードマップ0.19

**採用したのは、補正基準日の訂正と、不一致日の影響範囲を限定する訂正。予測の閾値や反復条件は変更していない。** 比較可能銘柄は49から52、報告保有割合20％以下の主対象は2から5に増えた。一方、四半期全体の成績は悪化した。この結果も保存し、修正後の方が儲かるとは主張しない。

## 何を、なぜ変えたか

| 変更案 | 判断 | 成績に依存しない理由・確認結果 |
|---|---|---|
| 補正の照合基準を取得日に合わせる | 採用 | 現在の補正後データには後の併合も反映される。同じ単位を照合するために必要。SMSI・GAMEは各146日で価格・出来高が整合し復帰 |
| 不一致を含む入力窓だけ保留する | 採用 | KAPAの価格差は2025年9月17日の1日だけ。今回の判定と反復に必要な入力範囲外なので、1〜3月の出来高判定は可能。差そのものは未解決のまま |
| 出来高0を有効な無取引日として扱う | 不採用 | LSHの当日には正の数量の約定1,286件がある。0を無取引と解釈できない |
| 四半期初めの1か月だけを採用する | 検証候補 | 集計期間を揃え、偶然に当たる機会を減らす理由はある。ただし初月に機関が買う根拠や、後半の買付けを除外する根拠はまだない |
| 値上がり条件を加える | 不採用 | 買い手の特定にならず、下落中の蓄積も落とし得る。追加効果を別期間で確認していない |

後の株式併合は品質の照合に使用した。日々の判定は元の出来高と、その判定日までの併合だけで計算する。不一致日の数値を補間したり、価格誤差の許容幅を広げたりはしていない。KAPAの古い価格を価格分析に再利用できるという認定でもない。

取得が不完全、補正前後の日が対応しない、不正な値がある場合は保留する。入力の過去窓に不一致があればその判定は不明、評価期間の判定が一つでも不明なら四半期比較も不明のまま。既存の前処理が持っていたこの規則を、一括処理にも適用した。

[最初に固定した条件](https://github.com/nekoromme/-institutional-flow-monitor/commit/aac72c5e373d2fb837a98fc12a97ecfeb4164a02)と、初回実行後の追加判断は[修正計画](QUALITY_REPAIR_PLAN.md)に残した。追加判断は、KAPAの不一致日を特定してから次の実行前に保存した。

## LSHは「取引なし」ではなかった

2026年1月5日のニューヨーク日付の1日全体を、日足・分足・約定で取得し直した。三つとも応答の全ページ取得が完了し、日足1件は出来高0、分足は0件、正の数量の約定は1,286件だった。

約定条件の内訳では1,283件が通常の取引単位に満たない少量取引の印を含み、残り3件は公式な始値・終値の報告だった。[Alpacaの生成規則](https://docs.alpaca.markets/us/docs/market-data-faq#how-are-bars-aggregated)では、少量取引は出来高を更新するが価格を更新せず、公式な始値・終値の報告は出来高を更新しない。足の価格が成立しなければ分足は生成されないため、**分足がないことと約定があることは両立する**。

一方、出来高0の日足が生成されている点は公式説明と整合せず、過去の日足処理の意味は未解決。約定を単純合計して日足へ置換することも今回はしていない。LSHは保留を継続する。COMMも必要日の欠損が残る。

## 修正後の実データ比較

同じ52銘柄で、公開報告合計が2025年12月末から2026年3月末に増えた割合を比較する。

| シグナルの集計終点 | 反復あり | 反復なし | 差 |
|---|---:|---:|---:|
| 1月末 | 8／11＝72.7％ | 18／41＝43.9％ | +28.8ポイント |
| 2月末 | 16／29＝55.2％ | 10／23＝43.5％ | +11.7ポイント |
| 3月末 | 17／36＝47.2％ | 9／16＝56.2％ | -9.0ポイント |

従来の49銘柄だけなら、同じ入力で判定は変わらない。今回の表の変化は主に3銘柄の復帰による。過去の取得回との判定ハッシュも一致した。指定5銘柄とCJMBの試行も不変。

主対象の5銘柄に限ると、四半期全体の反復ありは保有増加0／3、反復なしは1／2。低保有銘柄での優位性は確認できない。全体の1月の差だけで、主対象にも有効と判断しない。

両期に観測された同じ運用者だけの集計では、全52銘柄の差は1月＋25.7、2月−6.6、3月−10.4ポイント。報告の集計範囲による不安定さも残る。これは実際の機関売買の的中率や利益の比較ではない。

## 機関流入がなくても当たる構造を確認

独立で同じ分布の正の乱数を出来高に見立てた1万系列に、本体の既存判定をそのまま適用した。各系列は基準60日と反復準備4日を確保し、20・40・61日を比較。閾値や期間の最適値は検索していない。

| 評価する日数 | 一度以上の異常 | 一度以上の反復 |
|---|---:|---:|
| 20日 | 75.2％ | 23.5％ |
| 40日 | 94.5％ | 42.1％ |
| 61日 | 99.4％ | 58.2％ |

**現実の誤検知率ではない。** 乱数には機関流入の要因がなくても、四半期程度を「一度でも」とまとめるだけで、この頻度になるという条件自体の診断。現実の出来高には連続性、決算、株数変化などがあり、この数値を実市場へそのまま当てはめない。

なお、現在の基準は過去60個の小さい方から57番目を超えること。独立で同じ連続分布なら、新しい値が超える順位は61個中58〜61番目の4通りなので、理論上の一日当たりの確率は4／61＝約6.56％。乱数の実測は約6.59％だった。「95％の位置」という定義が誤りなのではなく、厳密な5％の検定や機関流入確率とは違う。ここを混同して条件を評価しない。

この結果から、四半期全体の異常有無を主な根拠にするのは弱いと判断する。反復には日々の異常を絞る役割があるが、それだけで機関買いを識別したとは言えない。一定の短い期間で機会を揃える比較には合理的な理由がある。ただし短縮すれば発見できる買付けも減り得るため、予測条件の採用は別期間の比較を待つ。

再計算：`python research/null_volume_check.py`。本体の判定を呼び、固定した乱数の初期値を使う。[乱数検証の結果](evidence/null-volume-check-2026-09-10.json)。
