# 下落を許容する異常出来高・試行4

2026-09-11。ユーザーの指摘に従い、価格停滞の条件を上下対称の値幅から上方向だけの制限へ変更した。

## 今回変えた条件

直近5営業日の直前終値を基準に、その5日間の高値が＋5%を超えないこと。下落率の下限はない。基準価格以下での大きな反発は含み得る。前20日間がその前60日より静かという条件、出来高異常の反復、既知14銘柄除外、89銘柄の対象、翌日始値購入・10営業日目終値売却・片道0.25%費用は固定した。すべての下落銘柄を拾う設定ではなく、事前の静けさは残っている。

旧条件で高安幅が狭くても、5日窓の初日に上窓を開けたケースは新条件では落ちる。新旧は厳密な包含関係ではない。新規候補日は171／119、除かれた旧候補日は1／0。取引件数は重複保有を避けた予定から算出する。

## 結果

| 条件 | 2023年 件数／平均損益 | 2024年 件数／平均損益 |
|---|---:|---:|---:|
| 以前の上下5%以内 | 12件／-2.91% | 9件／-0.54% |
| 上方向制限・出来高条件なし | 1095件／-1.28% | 756件／-0.80% |
| 下落許容＋異常出来高 | 100件／-0.51% | 75件／-0.61% |
| 追加案：通知当日は下げ止まり | 58件／-1.59% | 46件／-1.00% |
| 再試行：通知当日も下落 | 72件／-0.04% | 48件／+0.55% |

すべて1取引あたりの平均で、資産全体の利回りではない。下落許容の175取引は評価未解決0。旧条件の21取引より大幅に増え、2023年の平均は改善したが、両年で利益は出なかった。出来高なしの比較相手より平均は良いものの、購入日分布や銘柄分布も違うため出来高の因果効果とは断定しない。

## 何が弱かったか

**下落許容の親条件は、費用前でも平均が2023年−0.01%、2024年−0.11%とほぼ横ばい。** 往復約0.5%の費用を吸収する値上がりが得られていない。費用だけをゼロにすれば優位性が生まれる結果でもない。

新規に拾った取引は88／66件、平均−0.18%／−0.61%。新たな下落群の追加で2023年は改善したが、2024年も改善したとは言えない。過去5日下落群と非下落群の優劣も年によって逆になり、下落率だけを微調整する根拠は弱い。

通知当日の下げ止まりを確認する固定案は、両年で平均が悪化した。親条件の取引を通知日下落で分けると、当日下落群は61件＋0.26%／42件＋0.24%、非下落群は39件−1.71%／33件−1.68%。ただし、親条件の部分集計は独立して運用できる戦略の結果ではない。

この診断から「通知日にも売りが出た後の反発を拾う」という仮説を追加し、下落許容条件＋通知当日終値が前日終値より低い、だけで売買予定を組み直した。閾値を探さず0%境界と10日保有を固定。下げ止まり案と合わせて、累積戦略案は10となった。

## 判断

事前の合格条件を両年で満たしたか：親条件=False、下げ止まり確認=False、通知日下落の再試行=False。合格基準は30取引以上、平均正、最大利益1件除外後も正、比較相手より平均改善。追加案は親条件より平均改善も必要。

再試行の通知日下落案は72／48取引、平均−0.04%／＋0.55%で、親条件の−0.51%／−0.61%から改善した。ただし最大利益1件除外後は−0.54%／−0.25%。2024年の中央値も−1.43%で、多くの取引が安定して利益を生む結果ではない。この反発仮説は研究対象として残すが、本番採用はしない。

両年の診断から追加した反発案は事後探索であり、2024年も独立した未見評価ではない。見た期間で良い部分だけを選べば数字が上がる問題を避けるため、失敗案と累積試行数を保存し、2025年専用データは開いていない。本番通知条件は変更しない。

次は価格条件の細かい最適化より、前回実装した約定・直前気配の分類を、今回の下落許容候補にも同じ事前選択で適用することが候補になる。売りが多いのに価格が崩れない場合と、売りに押され続ける場合を比較し、価格だけでは分けられなかった中身を調べる。ただし売買主導方向と真の買い集めは同一ではなく、分類不明が多い場面を買い扱いしない。
