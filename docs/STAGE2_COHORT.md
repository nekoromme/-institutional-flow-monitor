# 2026年初の対象選びに使う資料と、確認候補200件

2026年9月10日／コード0.4.1／historical-frame-0.1

**2026年1月の対象選び用に2025年秋の保有報告を追加取得し、当時の報告に登場する普通株表記の証券3,181件から、最初に確認する200件を固定した。** 200件はまだ低保有銘柄群でも、比較用に採用済みの銘柄群でもない。

前回の5銘柄の出来高試行は[こちら](STAGE3_PILOT.md)。今回は対象選びの材料と日付を整える工程で、新たな銘柄の値動きやシグナル成績は見ていない。

## なぜ別の保有資料が必要か

2026年1月の対象を選ぶとき、2026年3月末の保有報告や、1月以降に公表された2025年12月末の保有報告は使えない。将来の結果を見て、都合のよい銘柄を過去の対象に加えてしまうため。

| 用途 | 今回使う保有期末 | 公表日の条件 |
| --- | --- | --- |
| 2026年初の対象選び | 2025年9月30日 | 2026年1月1日より前に提出された版のみ |
| 2026年1〜3月の答え合わせ | 2025年12月31日→2026年3月31日 | 前回の2026年6月1日時点の集計を維持 |

保有期末と公表日を別々に扱う。2025年9月末について12月に訂正された報告は使えるが、2026年1月以降の訂正は対象選びには使わない。同日の公表時刻が分からないため、境界日の提出も除く。

追加取得したのは、SECが公開する2025年9〜11月提出分の一括資料約85.6MB。10,422件の提出と3,267,091行の保有明細を含んでいた。既存の12〜2月提出分と合わせ、12月公表の訂正も反映した。[一括資料の公式一覧](https://www.sec.gov/data-research/sec-markets-data/form-13f-data-sets)

## 実際に除外できた未来の資料

取得済みの計3本から、2025年9月末について2026年初に利用できた版を選んだ。

- 同じ9月末の保有でも、2026年1月1日以降に提出された192件を除外。
- 9月末より後の保有期末に関する21,801件を除外。
- 選択した運用者のうち9,771件は既存の表の整合性検査を通過。145件は訂正や件数の問題で保留。

9,771件は「重複を完全に解消した運用者数」ではない。表を取り込むための検査に通った件数で、共同報告や保有率の認定は別途必要になる。

今回も、現在取得した過去の提出データを復元に使う。当時ダウンロードしたファイルそのものではなく、後日のSEC側の抽出修正がないことまでは保証できない。原資料のURLと内容の指紋を保存した。

## 200件の作り方

[2025年7〜9月期の公式証券一覧](https://www.sec.gov/files/investment/13flist2025q3-txt.txt)を、当時の保有報告と照合した。SECは証券番号、発行者、株式種類、追加・削除の印の列を定義している。[列の公式説明](https://www.sec.gov/rules-regulations/staff-guidance/official-list-section-13f-securities)

最初の対象範囲は、公式表の株式種類が `COM` または `COM SHS` の普通株表記で、削除印がない証券に限定する。これは米国普通株全体を網羅する条件ではなく、複数種類の普通株などを外す狭い出発点。オプション取引可能の印だけを理由に株式を外さない。

| 数えたもの | 件数 |
| --- | ---: |
| 公式一覧の上記の範囲 | 3,284 |
| 当時利用できた表に、有効な株式の保有行が見つかった証券 | 3,181 |
| 有効な保有行が見つからなかった証券 | 103 |
| 最初に詳細確認する件数 | 200 |

103件は保有ゼロではない。未報告、省略、書類の不備、株式種類の表記などで見えない可能性がある。この一覧から対象を作る限り、結論の範囲は「今回の規則で報告を観測できた証券」に限られる。機関が全く保有していない銘柄まで検証したとは扱わない。

3,181件を証券番号と固定文字列から作る数値で並べ、先頭200件を抽出した。会社名順や現在の時価総額順ではなく、入力順を変えても同じ結果になる。抽出数200は調査作業の区切りで、統計的に十分な標本数を保証する数ではない。

この200件の選択には、将来リターン、将来の保有変化、現在の上場銘柄一覧を使わない。UAVSなど既存5銘柄を優先して加える処理もない。除外が出たら理由を残し、気に入った銘柄への手動交換をしない。追加確認が必要なら、同じ順序の続きへ進む。

公式一覧は「その期の証券番号の照合材料」。今回取得した版の正確な過去の公開時刻は未確認なので、この一覧だけで厳密な当時の上場一覧が復元できたとはしない。

## 指定5銘柄の対象選び用の値

同じ時間の条件を5銘柄にも適用した。以下の合算は共同報告などの未解決部分を残す点検用の値で、機関保有率ではない。

| 銘柄 | 2025年9月末の報告株数の点検用合算 | 使える発行済み株数 | 分母の基準日 |
| --- | ---: | ---: | --- |
| UAVS | 2,468,213 | 36,734,690 | 2025年9月30日 |
| QMCO | 865,029 | 13,333,000 | 2025年9月30日 |
| MU | 878,108,557 | 1,122,466,035 | 2025年9月26日 |
| ONTO | 47,269,930 | 49,003,572 | 2025年7月15日 |
| AAOI | 39,671,261 | 68,065,000 | 2025年9月30日 |

UAVSとQMCOは、11月公表の原決算書で普通株の発行済み株数を照合した。QMCOは表が千株単位なので、13,333を13,333,000株として読む。資本金の金額や、発行を認められた上限株数と混同しない。[UAVS原決算書](https://www.sec.gov/Archives/edgar/data/8504/000143774925035221/uavs20250930_10q.htm)、[QMCO原決算書](https://www.sec.gov/Archives/edgar/data/709283/000070928325000085/qtm-20250930.htm)

原書類の表紙には、それぞれUAVS・NYSE American、QMCO・Nasdaq Global Marketという普通株の登録情報もあった。これは11月の書類に記載された情報で、2026年初までの継続上場を単独で保証するものではない。

UAVS・QMCOにはそれぞれ保留した提出者1件、相手未解決の参照5件が残る。その他3銘柄には分母の日付ずれ・種類確認も残るため、5銘柄とも低保有認定は保留した。

## 比較対象として採用するまでの確認

抽出した200件には、ファンドや取引状況の確認を要する名前も含まれていた。普通株に似た表記だけで、米国上場の事業会社と決められない。そのため、次の確認を通るまでは採点対象にしない。

1. 当時の証券番号・銘柄コード・普通株の種類・上場状況・事業会社かどうか。
2. 同じ種類の発行済み株数と、重複・省略を点検した報告保有株数。当時の報告比率を計算できるか。
3. 当時の規模、売買の活発さ、業種、必要な価格履歴。データ不足で除外する場合は件数と理由を残す。

その上で低保有群を作り、**同じ低保有群の中で候補が出た銘柄と出なかった銘柄を比べる**。高保有の大型株だけを比較対象にして、別の性質の差をモデルの効果と取り違えない。

規模・売買の活発さ・業種は比較条件で、通知モデルへ加点する変数ではない。モデルは既定の出来高と反復だけを維持する。四半期ごとの確定ラベル数と、候補なしの比較銘柄が十分に得られるかを先に確認し、少なければ「優劣不明」とする。

現時点の認定済み低保有銘柄は0件、対応づけ済み比較対象も0件。この工程で200件の低保有銘柄を確保した、と読み替えない。

## 保存・再実行・検証

- [候補200件・時点の除外記録・5銘柄の詳細](evidence/historical-frame-2026-09-10.json)
- 全3,181件の一覧はコマンドで再生成し、公開記録の指紋と比較できる。
- 新しいデータ取得、銘柄追加、株数の修正があれば、結果と版を残して再抽出する。

```bash
python -m flow_probe.cohort --fetch
```

不足するSEC資料だけを取得する。3本の一括資料を全く持っていない環境では約275MB。既存環境では追加分だけ。取得済みなら `--fetch` は不要。APIキーや有料契約は使わない。GitHub実行環境からのSEC取得制限は残るので、今回の大量資料の照合はローカルで実行した。

ローカルで69テストに合格。同日・将来の訂正を加えても過去の選択が変わらないこと、12月の訂正は反映すること、将来の発行済み株数を除くこと、抽出順の再現性、未観測をゼロとしないことを確認した。GitHubでの結果は実行後に追記する。
