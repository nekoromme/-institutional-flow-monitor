# CJMBの出来高判定と、四半期の保有報告との対応

2026年9月10日／コード0.5.3／cjmb-volume-pilot-0.1

**CJMBの実データを既存モデルで判定し、2026年1〜3月の61営業日で異常出来高8日、うち反復条件を満たす日5日を記録した。** 同じ四半期の公開保有報告の合計は131,419株減っていた。出来高と保有報告を対応づける処理は通ったが、機関流入の検出精度を実証した結果ではない。

## 今回の固定条件

対象は前段階で決めたCJMB。判定期間は2026年1月1日〜3月31日で、基準の過去窓を作るため、2025年9月1日からの日足も取得する。結果を見て期間や境界値を変更していない。

モデルは既存5銘柄の試行と同じ処理を使う。

1. 自分自身の過去60回の通常の長さの取引日の出来高を並べる。当日を含めない。
2. 当日の出来高が、小さい方から57番目の値を厳密に上回れば異常とする。これは過去分布の95％の位置に相当する。
3. 当日が異常で、直近5取引日のうち2日以上が異常なら「反復」とする。

短縮取引日は異常判定と過去60日の基準から外す。ただし直近5取引日の並びからは消さず、5日のうち判断できない日があれば反復は不明にする。欠けた出来高を0で埋めない。

日足はAlpacaの全米市場統合データを明示指定する。提供元の日足の範囲を使用し、通常取引時間だけの出来高とは決めつけない。銘柄コードの自動的な過去名への読み替えを停止し、補正前と株式分割・併合の補正後を取得して比較する。[提供元の日足仕様](https://docs.alpaca.markets/us/reference/stockbars)

補正値に未確認の違いがあれば、そのまま採点へ進めない。取得できたことと、株数単位を揃えて使えることを別に確認する。

## 保有報告との対応は1銘柄・1四半期

前段階の原表照合後の報告合計は、2025年12月末の732,311株から2026年3月末の600,892株へ、131,419株減っていた。分母の発行済み株数も変わり、確認用の割合は15.07％から10.64％へ低下している。[二期の保有比較と原表の修正](STAGE3_CJMB_COMPARISON.md)

今回の異常日と反復日は、すべてこの一つの四半期の比較に対応させる。異常日が何日あっても、それを独立した複数の的中・外れとして数えない。対応づけた数は1銘柄・1四半期、的中率の計算対象に認定した数は0のまま。

期中に機関が買ってから売った場合、期末残高だけでは分からない。公開保有報告の不明点も残っているため、報告合計の減少を機関売りの確定ラベルにはしていない。したがって、異常が出た場合も直ちに「モデルが外れた」と採点しないし、「機関が買った」とも表示しない。

保有報告は出来高を判定した後に対応づける。5月などに公表された株数を、1月の判定条件へ渡す構成にはしていない。

既存5銘柄の出来高判定の指紋は `eead8794c7412db7115f0d3330e7fd54f03ab0a96b29de96cce405caf55b622e` で変わらなかった。CJMBの判定の指紋は `4661309984517166032c696e156f78ed3405b58284c81e9d3bb04eefc236e4d4`。

価格、出来高、判定に使った過去窓などの原数値は、実行環境内だけに保存する。公開レポートは取得・欠損等の件数、指紋、日付ごとの判定結果と保留理由で構成し、価格・出来高の原数値は含めない。

GitHubの実行環境が消えると原数値は残らない。コード・取得条件・指紋は保存したが、取得時点の市場データを完全に再現するための非公開の永続保存先は未整備。再取得した過去データが後日訂正される可能性もあるため、当時の通知を復元したとは扱わない。

## 次の工程

固定候補の残りの株式種類・分母・保有報告の確認を広げ、異常が出なかった銘柄も含む比較群を作る。比較結果を見る前に、低保有の対象条件、四半期単位の集約、未観測や機密欄の不明を扱う規則を固定する。

そのうえで、単純な出来高異常だけの場合と反復も求める場合で、後の報告保有増加の観測割合がどう違うかを比較する。今回の1銘柄・1四半期を何件もの正解例として数えず、この結果を見て境界値を調整しない。実際の通知が書類にどれだけ先行できるか、将来の値動き、非公開の原データ永続保存も未完了として残す。
