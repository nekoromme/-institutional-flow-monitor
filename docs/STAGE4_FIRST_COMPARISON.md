# 初回の一括比較：残る52件の点検から54銘柄の実データ集計まで

2026年9月10日／コード0.6.1

追補：[期間集約・保有集計・データ品質の要因診断](STAGE4_FACTOR_DIAGNOSTICS.md)を実行済み。下記は初回比較時点の記録。

**残る52件の点検、比較条件の事前固定、54銘柄の実データ取得、二期の保有集計との初回比較まで実行した。現時点で反復条件の優位性は確認できなかった。** 四半期を通して判定できた49銘柄すべてで異常出来高が一度以上発生し、単純な異常の有無では比較相手が残らなかった。反復条件では比較相手が残ったが、全体の報告保有増加の観測割合は反復あり50.0％、反復なし53.3％だった。

## 今回進めた範囲

残っていた52件をまとめて点検し、50件の普通株数を追加確認した。確認済みは13から63銘柄へ増えた。以前の65件の数値候補はすべて点検済みとなり、2件は理由付きで保留した。

| 固定200候補の扱い | 件数 |
| --- | ---: |
| 同期期末の分母を得られず、今回の比較から除外 | 135 |
| 普通株数の照合で保留 | 2 |
| 普通株数は確認できたが、報告合計の割合が100％超 | 6 |
| 普通株数は確認できたが、当時の登録廃止等の確認が必要 | 3 |
| 公開報告を使う今回の試行対象 | 54 |

普通株数の保留はOCSLとRLAY。OCSLは同じ可視行が複数あり、今回の照合方法では対象箇所を一意に固定できなかった。RLAYは銘柄対応資料の額面と株数の記載行の額面が食い違っていた。いずれも数値を都合よく採用せず保留した。

登録廃止等の確認が残るRVPH・MRUS・VHCも、今回の群へ入れなかった。届出の存在だけで実際の上場廃止日や売買不能を確定したという意味ではない。全200件のうち何を除いたかは、固定した比較条件の記録に残している。

## 比較条件は新しい結果を見る前に保存

[条件を固定した変更記録](https://github.com/nekoromme/-institutional-flow-monitor/commit/2cd014f0a9bf78a6081777cbb33fde18fc058c10)を先に保存してから、54銘柄の市場データ取得と後の保有報告の一括集計を実行した。すでに見た指定5銘柄やCJMBの結果があるので、2026年1〜3月を未知の期間を使った最終検証とは扱わない。

| 項目 | 今回の固定内容 |
| --- | --- |
| 対象を選ぶ基準日 | 2026年1月1日 |
| 選定用の保有・分母の期末 | 2025年9月30日。基準日前に公表された資料だけを使用 |
| 主な試行対象 | 公開報告の株数合計÷同期期末の普通株数が20％以下の6銘柄 |
| 補助の試行対象 | 54銘柄中、同割合が低い下位3分の1の18銘柄 |
| 全体の参考集計 | 54銘柄。低機関保有を確認した54銘柄ではない |
| 出来高の判定期間 | 2026年1月1日〜3月31日 |
| 基準の出来高 | 自分自身の過去60回の通常取引日。当日を含めない |
| 異常判定 | 過去60日の小さい方から57番目の出来高を厳密に超える |
| 反復判定 | 当日が異常で、直近5取引日のうち2日以上が異常 |
| 保有報告の比較 | 2025年12月末と2026年3月末。2026年6月1日より前の提出を使用 |
| 標本の単位 | 1銘柄・1四半期。同じ銘柄の複数の異常日は1件として扱う |

下位3分の1の境界は約50.63％だった。集団内で低いだけでは、本来の目的である「機関がまだ少ない」には合いにくい。そこで主な試行には絶対水準20％以下という仮条件を置いた。20％は優位性が検証済みの数字ではなく、今回から検証する研究用の条件。値動きや後の保有増加を見て最適化した境界ではない。

主な試行対象はLSH・KAPA・SMSI・GAME・HYFM・CJMB。当時の会社届出による上場記載を代理情報として使い、機関保有の集計上の不明点も保持している。完全な機関保有率が20％以下と認定した意味ではない。

## データの品質と保留

54銘柄で補正前の日足7,831件と補正後の日足を取得。109回の要求、約1.65MB、約54秒で取得・判定を実行し、通信の再試行は0回だった。これは今回の少量の日足取得の実測であり、歩み値を広範囲に取得する費用や処理量を示すものではない。

| 処理結果 | 件数・銘柄 |
| --- | --- |
| 取得を試みた銘柄 | 54 |
| 既存モデルで日別判定まで実行 | 51 |
| 未確認の補正差で保留 | 3：SMSI・GAME・KAPA |
| 四半期の判定に不明が残る | 2：LSH・COMM |
| 四半期の比較に使用できた銘柄 | 49 |
| 異常出来高が一度以上 | 49／49 |
| 反復条件が一度以上 | 34／49 |

LSHは日足146日がすべて存在するが、2026年1月5日の出来高が0だった。この日またはこの日を含む過去窓について、既存の「出来高が正でなければ不明」という規則が働き、評価期間の60日が判定不能になった。COMMは取得期間の取引日53日が欠け、評価期間の53日が不明になった。

この二つを同じ「異常なし」にはしていない。初回の実行記録では不明の原因を直接追えなかったため、原因ごとの件数とゼロ出来高の日付を残すよう記録を補い、再実行した。判定結果は全銘柄で変わらなかった。

株式分割・併合の補正は、補正前と補正後を照合した。未確認の差がある銘柄は一銘柄ごと保留した。提供元の現在の補正が将来の併合等を反映している場合もあり、差の原因を推測して倍率を当てはめていない。今回の「保留」は銘柄の異常出来高がないという判定ではない。

四半期内の判定が一日でも不明なら、その銘柄の四半期の当該判定も不明とする。欠損を0にせず、不明を「異常なし」の比較相手へ混ぜない。短縮取引日の除外と反復の不明規則は既存モデルのまま。

## 公開保有報告による初回の比較結果

次の表の分子は報告株数合計が増えた銘柄数、分母は各条件の判定と二期の観測が揃った銘柄数。両者の割合の差は参考値であり、統計的に確かな改善の判定ではない。

| 対象群 | 反復あり | 反復なし | 割合の差 |
| --- | ---: | ---: | ---: |
| 報告割合20％以下：候補6、使用2 | 0／1（0％） | 0／1（0％） | 0ポイント |
| 下位3分の1：候補18、使用14 | 6／10（60％） | 2／4（50％） | ＋10ポイント |
| 全体参考：候補54、使用49 | 17／34（50％） | 8／15（約53.3％） | 約−3.3ポイント |

主な試行対象で使用できた2銘柄はCJMBとHYFM。CJMBは反復あり、HYFMは反復なしで、いずれも報告合計は減っていた。6候補のうち4候補が保留となっているので、低保有銘柄の一般的な結果とは解釈できない。

両期に正の保有が観測された同じ運用者だけに限定すると、次のようになった。

| 対象群 | 反復あり | 反復なし | 割合の差 |
| --- | ---: | ---: | ---: |
| 報告割合20％以下 | 1／1（100％） | 1／1（100％） | 0ポイント |
| 下位3分の1 | 7／10（70％） | 3／4（75％） | −5ポイント |
| 全体参考 | 21／34（約61.8％） | 10／15（約66.7％） | 約−4.9ポイント |

下位3分の1では、集計方法を変えるだけで反復条件の見かけの優劣が逆転した。比較元と比較先の両方に報告がある運用者だけを残す方法にも選択の偏りはあるため、こちらが完全な正解という意味ではない。

単純な「四半期中に異常出来高が一度でもあった」という条件では、三つの対象群すべてで異常なしの比較件数が0になった。該当率や差を無理に計算して、有効性が分かったことにはしていない。

比較しているのは、通知した銘柄で「観測された公開報告の株数合計が増えた割合」が高いかどうか。実際の機関買いの的中率や利益ではない。一方の期で保有が観測されない銘柄は、保有ゼロや全売却とせず結果不明にした。

保有合計の増減だけでなく、両期に正の保有が観測された同じ運用者だけの増減でも集計した。この二つの結果が変わるなら、報告へ新しく現れた・現れなくなった運用者の扱いが結論を左右している。

保有報告の品質上の警告を一つでも除く条件では、54銘柄すべてが対象外になった。この厳しい条件の比較件数は0、割合と差は計算不能のまま保存した。ここを隠して、観測可能な部分の結果を確定した機関保有の結果として出さない。

CJMBは前工程で原表を全行照合した、修正後の二期の記録を使用した。その他の銘柄へこの例外を流用せず、個々の提出書類の件数不一致等の警告を保持している。

## 現時点での判断

**今回の結果を理由に通知を本番運用したり、反復条件を強くすれば儲かると判断したりしない。** 反復の追加価値を確認できなかった一方、低保有の主対象は2銘柄しか残らず、これで手法全体を棄却するにも材料が足りない。

今回分かった設計上の問題は、日々の異常判定を「四半期に一度でも」という単位へまとめると、ほぼ全銘柄が該当し得ること。仮に毎日の異常確率が5％で日ごとに独立なら、61日間に一度以上起きる確率は約95.6％になる。これは説明用の仮定であり、実際の出来高が独立・一定確率という認定ではない。日々の珍しさと、四半期単位で銘柄を選別する力は別物だった。

次の工程は、まず主対象のSMSI・GAME・KAPAの補正差とLSHのゼロ出来高が妥当かを原資料・提供元データで点検し、比較対象の脱落を減らす。ゼロ出来高を一律不明にする規則が対象銘柄に合うかも、別の版の検証課題とする。そのうえで別の四半期の対象群を作り、同じ条件を再検証する。異常日数や反復回数で順位を付ける修正案は、今回の期間へ都合よく合わせず、新しい版の条件として固定してから別期間で評価する。通知を正式資料より何日早く出せたか、通知後の利益、非公開の原データ永続保存は未完了。

一四半期の同じ市場に属する銘柄は互いに影響を受けるため、各件が独立した実験とは言えない。今回の小標本だけで統計的に確かな改善と主張しない。対象群の違い、保有の未観測、株式発行、決算などの影響も残る。四半期内に買って売った場合も期末報告では追えない。

今後は今回の条件と結果を保存し、別の四半期や新しく到来する期間で比較を繰り返す。今回の結果を見て条件を変更する場合は新しい版とし、その版の評価に同じ期間だけを再利用しない。

## 実行と再現

ローカルと[初回のGitHub実行](https://github.com/nekoromme/-institutional-flow-monitor/actions/runs/34463405277)で129件のテストに合格し、54銘柄の実取得も成功した。不明理由の記録を補った[再実行](https://github.com/nekoromme/-institutional-flow-monitor/actions/runs/34463842233)でも129件に合格し、全銘柄の判定の指紋は初回と一致した。既存5銘柄とCJMBの個別試行も結果が変わらなかった。

保有資料は既存の公式一括資料2本・7,296,094行を今回の54銘柄用に抽出した。原書類の照合と保有集計はこの作業環境、市場データ取得は登録済みキーを使うGitHubの実行、比較表の計算は保存した両結果を使ってこの作業環境で行った。テスト合格は処理の検証であり、機関流入の検出精度の証明ではない。

```bash
# 保存済みの原書類から、残る52件の確認を再現する。
python -m flow_probe.class_full
# 保存済みの二つの一括資料から、固定54銘柄の保有を集計する。
python -m flow_probe.batch_holdings
# 登録済みの秘密設定で固定54銘柄の日足を取得・判定する。
python -m flow_probe.batch_market
# 公開済みの今回の派生結果から、比較表を再計算する。
python -m flow_probe.batch_compare
```

市場データの原数値は実行環境内だけに保存し、公開ログや公開リポジトリへ出していない。その実行環境が消えると原数値は残らないため、今回も市場データの取得時点の版を完全に再現する非公開の永続保存先は未整備。派生結果とその指紋、取得条件、コードは保存した。
