# 2023〜2024年：保存データで初回の損益比較

2026年9月10日。**3年分のデータ整備から、確認済みの一部候補を使う探索的な損益比較まで接続した。本番採用は保留する。** 2025年を通知対象とする専用データセットは復号せず、2025年の通知成績も計算していない。2024年末の通知を10取引日評価するため、2024年ファイルに付属する2025年1月の退出価格は使用した。したがって2025年の価格を一切見ていないという意味ではない。

2023年22銘柄、2024年23銘柄。年初より前に公表された資料から固定した候補のうち、発行会社・証券番号・当時のコードを一次照合して価格を追加収集できた範囲である。正式な全対象・低機関保有対象の認定を終えた集合ではない。初期の59銘柄とも結果を混合しない。詳細な対象の限界は[前回の照合](HISTORY_IDENTITY_AND_PRICES.md)を参照。

## 固定した条件

- 過去60回の通常営業時間の出来高分布で上位5％を超える日を異常とする。判定当日の値を基準へ混ぜない。
- 反復は当日が異常、かつ直近5取引日に2回以上。短縮営業日・欠損がある窓は不明のまま。
- 株価方向は通知時の終値が5取引日前より上か。価格方向だけの比較相手にも、反復版と同じ情報品質を要求する。
- 通知の翌営業日の始値で購入、10取引日目の終値で評価。同一銘柄の重複保有を抑止。売買費用は片道0.25％、別に0／0.5／1％も点検。
- 日足の参考価格による取引別の平均。配当、実際の約定、資金制約、税、資金全体の利回りは含まない。市場指数との比較も今回は未実施。

条件と比較相手は損益を見る前に[検証計画](../research/history/VALIDATION_PLAN.md)へ固定した。今回は閾値・保有期間・銘柄を成績に合わせて変更していない。

## データ品質の修正を成績と分離

従来の許容幅では、併合のある3銘柄の258銘柄日が価格不一致になった（準備・退出期間を含む）。出来高の換算は許容幅内。価格の残差は最大約0.005ドルで、補正後の価格を1セント単位へ丸める説明と整合した。

提供元の公式資料では丸め仕様を確認できなかったため、従来ケースを保存した上で、**元の値との誤差が半セント以内、補正後の4価格すべてが1セント刻み、その他の品質条件は従来通り**という追加ケースを実施した。[追加比較を固定した記録](../research/history/PRECISION_REVIEW.md)。252銘柄日が説明可能となったが、VCNXの6日はこの条件を満たさず保留した。不一致を無条件に許容したものではない。

この変更の理由は、併合銘柄を誤って欠損扱いする偏りを調べること。実際、主候補の平均損益は両年とも悪化した。公式仕様が確定した修正とは呼ばず、以下は**丸め仮説付きの探索結果**とする。

## 今回分かった、優位性を弱める要因

1. **大きな当たりへの依存。** 反復＋株価上昇は2024年平均＋3.07％だが、最大1件を除くと−0.63％。その1件はTKNOの2024年7月15日通知で参考損益＋184.73％。2023年も最大1件を除くと−1.38％。安定した改善という結論は出せない。
2. **費用で消える小さな利益。** 2023年の反復＋株価上昇は費用前＋0.22％、片道0.25％を入れると−0.28％。反復版も片道0.5％で−0.37％。実際の気配差と注文数量が必要になる。
3. **品質エラーによる選別。** 丸めと説明できるデータを戻すと主候補の平均は2023年＋0.48→−0.28％、2024年＋3.97→＋3.07％。除外の影響を無視して好成績を採用してはいけない。
4. **反復・価格方向の効果が一定でない。** 2023年は反復版＋0.13％に対し、価格方向を加えると−0.28％。2024年の反復版＋1.13％は出来高のみ＋1.44％より低い。条件を増やすほど良いわけではない。

価格方向だけとの平均差はあるが、各モデルの購入日や重複保有の抑止で取引集合が違う。同じ銘柄・同じ時期の比較や市場調整を行う前に、出来高の追加価値が統計的に確立したとは言わない。買い手の身元を識別した結果でもない。

## 判断と次の工程

**売買条件は据え置き、本番採用も保留。** 株数を反映する会計処理は採用し、丸め対応は仮説付きの比較ケースとして維持する。最大の当たりに強く依存するため、さらに条件を足すより、残りの当時の候補・上場状態・証券種類の照合を広げることを優先する。併行して丸め仕様とVCNXの6日を確認し、比較用指数と実行価格・数量の検証へ接続する。2025年は対象・品質・比較手順を固めてから一度だけ評価する。

28件のデータ・会計テストに合格。併合で架空の利益が生じないこと、現金権利と欠損の区別、未来の併合による過去の通知不変、丸め許容の境界、出来高の不一致を救済しないことを検証した。GitHub Actionsでも実データの処理と暗号化保存を完了した。
