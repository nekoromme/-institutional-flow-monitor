# 通知後の利益を主目的にした検証計画

2026年9月10日。ユーザーによる目的の明確化を反映。主目的を変更した記録であり、既存条件の投資成績が判明したという意味ではない。

実施状況：初回の価格損益・失敗原因の診断を完了。[実測結果](STAGE4_RETURN_DIAGNOSTICS.md)と[次の比較条件](NEXT_RETURN_VALIDATION_PLAN.md)を参照。以下は主目的を変更した時点の計画を残したもの。

## 目的と仮説

主目的は、普段と異なる売買から、通知を受けて買った後にも値上がり余地のある候補を見つけ、売買費用と下落リスクに見合う利益を得ること。大口の情報・調査・確信に伴う買付けの後追いは、そのための仮説の一つ。買い手が機関かどうかは成功の必須条件にしない。

大きな買付けが、未知の好材料や高い予測能力を保証するわけではない。例えば指数に連動する運用では、個別企業の未公開の好材料を発見したこととは別の理由で保有する。[米国証券取引委員会の指数連動運用の説明](https://www.investor.gov/introduction-investing/investing-basics/investment-products/mutual-funds-and-exchange-traded-4)。したがって「大口らしいから成功」とせず、追随した側の損益を測る。

今後の主指標は費用控除後の平均損益と下落リスク。勝率、勝った時・負けた時の大きさ、通知件数、比較対象との差を併記する。後の機関保有増加は補助的な説明資料へ変更する。保有増加が見えなくても利益予測が再現すれば採用候補にできる。

## 直ちに変える作業順

次は既存モデルの通知後の損益を測る。追加の機関保有報告の照合や、2026年4月の機関保有率の完全確定を、最初の損益診断の前提にしない。既存の当時の対象候補・銘柄識別・市場データ品質確認は再利用する。

まず2026年1〜3月・事前に固定した54候補を使う。結果が判明しない銘柄を削除して52銘柄だけの好成績を作らず、取得不能・約定不能・通知不能を54候補の母数から別記する。低保有の群は重要な分析対象として残すが、現在確認できる少数例だけから最適な保有割合を探さない。

1〜3月は既に多数の診断に使った探索期間。ここから改善案を作ることは許すが、その期間だけで採用を正当化しない。時系列順の別期間で比較し、結果を見る前に対象と条件を保存する。当時の上場・識別・取引可能性の点検は必要で、現在生き残った銘柄だけへ置き換えない。

追跡期間の境界を明確化：初回は3月末の通知を最大20取引日追跡するため、4月末までの価格を取得する。従来の「4〜6月以降」は、購入通知の次の比較では**5月以降**へ変更する。4月の損益を案作りと検証の両方へ使わない。過去の接続試験で後の価格を一部取得した銘柄もあるため、「一切触れていないデータ」とは呼ばず、新しい通知・損益の結合結果を見る前に条件を固定した別期間の比較とする。

## 初回の売買評価で固定するもの

| 項目 | 初回の定義 |
|---|---|
| 比較モデル | 現行の異常出来高のみ、現行の反復追加。60日の基準・95％位置・反復2／5はまず変更しない |
| 通知対象日 | 四半期全期間。四半期初めの20日だけに制限しない |
| 購入基準 | 日足が確定し、通知を受け取れたとする時点より後の、次の通常取引開始時。通知日の終値で買えたとしない |
| 保有期間 | 購入日を1日目とする10取引日目の通常取引終了時を主な売却基準。5・20日は補助として全て報告 |
| 出口 | 初回は期間固定。都合の良い高値で売る計算や、利益確定・損切りの境界の同時最適化はしない |
| 重複 | 同一モデル内では保有中の同一銘柄の追加購入なし。売却日までの通知は記録だけ。次の取引日以降の通知から再び候補にできる |
| 費用 | 初回の仮定は購入額・売却額の各0.25％を不利に計上。各0、0.5、1％の場合も併記。実際の手数料・売買価格差を計測した値とは区別し、結果の良い費用仮定を選ばない |
| 株数・配当 | 併合・分割で数量を揃え、保有期間中の配当も調べる。価格差だけなら総合的な投資収益と呼ばない |
| 最初の比較単位 | 同額を投じた1回の取引。総資産の運用利回りではない。同時保有数・資金制約を伴う運用成績は次の評価で別に計算 |

注文の種類によって価格や成立の保証は異なるため、日足の始値を必ず取得可能な買値とは扱わない。[注文と成立価格についての公式説明](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders)。最初の日足による価格診断と、分足・約定・気配を使う執行確認を区別する。取引停止や売買不能、銘柄変更に伴う結果不明を、ゼロ損益や勝ちへ置き換えない。欠落した損失を含め得る場合は成績の限界として示す。

基準の情報時刻、購入日、売却日、入力資料の版を各事例に保存する。配当・株数変更・手数料・売買価格差・為替は異なる要因として扱う。最初は米ドル建て・個人の税引前の研究値とし、日本円での手取り利益とは呼ばない。

## 数字から逆算して改善案を作る手順

損失が集中した状況や、利益を取り逃した状況を探索期間で見つける。原因候補、作用の仕組み、変更案、不利益となるケースを一緒に記録してから別期間へ進む。合理的な説明は変更候補を絞る材料であり、それだけで偶然への適合を否定する証拠にはしない。

| 観測する失敗 | 検証する仮説 | 次に試せる少数の変更 | 逆効果の可能性 |
|---|---|---|---|
| 通知後より通知前に上がっている | 発見・購入が遅い | 最初の異常と反復後の購入を同じ事例で比較。翌朝の買値の上限を検討 | 早い購入は誤検出が増え、買値制限は強い上昇を逃す |
| 出来高増加後に売られる例が多い | 大きな売りや一時的な取引を拾っている | 当日中の価格の位置、継続性など一つを追加して比較 | 下落中の本当の蓄積を落とす |
| 費用前は良いが費用後に消える | 売買が薄く、実行価格が不利 | 売買価格差・取引金額・注文量に沿って対象を絞る | マイナー銘柄の初動も減る |
| 市場全体が上がった日にだけ良い | 単なる市場上昇を拾っている | 同じ日に買った市場全体・同程度の銘柄と比較 | 相場ごとの細分化を増やすと偶然を拾う |
| 少数の急騰だけが平均を支える | 再現性か、一部事例への依存か | 中央値、最大損失、大当たりの寄与、銘柄を一つずつ除く影響を確認 | 本来の利益が少数の大当たりに集中する戦略を誤って捨てる |

上の行は現在の損失原因が確定したという意味ではない。実損益をまだ計算していないため、初回の診断項目として固定する。利益を得るために最適化すること自体は許可されている。検証用の期間まで何度も見て条件を選び直すことを避ける。

## 採用するために必要な証拠

旧・新を同じ期間・取引可能な対象で比較し、費用後の損益、損失側の大きさ、件数、投入資金・拘束日数を揃えて判断する。比較相手は現行条件、単純な異常条件、同日の市場全体、通知していない同程度の銘柄。完全な業種・規模調整が未実装なら、その段階で断定しない。

改善案を作った期間と、採用を決める期間を分ける。保有期間が境界をまたぐ取引を分離し、同じ値動きを両方へ入れない。一つの変更ごとに試行数と却下理由を残す。勝率だけが上がって平均損失が大きくなる、利益が費用仮定一つで消える、少数の事例だけで符号が変わる場合は保留する。少し近い設定でも働くか確かめるが、最良値を再探索した結果とは区別する。

多数の試行から過去の最高成績を選ぶと、偶然への適合が生じ得る。[Baileyほかの原論文](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。利益が増える可能性は検証できても、必ず優位性を作れるとは保証しない。変数を増やしても再現しなければ採用しない。
