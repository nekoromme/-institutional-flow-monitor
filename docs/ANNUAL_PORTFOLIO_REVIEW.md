# 資金全体の年間成績と指数比較

2026-09-11。1取引平均からの単純な年率換算ではなく、現金・同時保有・年またぎを含む口座評価を実行した。主表示は2023年初から2024年末まで連続運用した場合の各年利益率と、2年間の複利平均年率。将来の予想利回りではない。

## 資金管理の前提

初期資金100万円相当、1回の購入は費用込み10万円相当で固定。最大10保有、借入なし、端株を許容。資金不足なら見送る。同時候補は銘柄名順。寄付き購入には当日の引け売却代金を使えない。損益は米ドル基準で、円額は為替を固定したイメージ。年が変わっても現金や保有をリセットしない。

売買費用は片道0.25%。税・為替変動・配当・待機現金利息を主計算に含めない。既存の翌営業日始値購入・10営業日目終値売却を維持。未決済保有は年末終値で評価する。指数の継続保有も年末の強制売却を行わず、将来の売却費用は引かない。

## 年またぎを修正した理由

最初の実行は年ごとに現金開始する独立評価だった。最新候補は2023年＋10.56%、2024年＋1.44%になったが、2023年末の6保有を翌年に引き継がないため、そのまま連続運用の年利として並べられない。独立評価は監査用に残し、主結果を連続運用に修正した。2024年−2.33%には前年末保有の損益が含まれる。

重複する5720行の価格・出来高の整合性を検査して年別入力を接続し、2023/2024のシグナルから重複保有なしの売買予定を一続きで生成した。年初のリセットで不利な持ち越しを消すことを避けた。初期資金・購入額・保有上限を結果を見て最適化していない。

## 再現と限界

[最初の独立年評価](https://github.com/nekoromme/-institutional-flow-monitor/actions/runs/34559833955)、[年またぎを含む主評価](https://github.com/nekoromme/-institutional-flow-monitor/actions/runs/34560112352)。65テスト後、年またぎと価格単位の整合性検査を加えて67テストを実施。各年利益率の複利積が2年後評価額と一致し、前年末保有と翌年開始保有が一致することを確認した。

指数データは既存のAlpaca読み取り専用処理でSPY/IWMの日足を取得。分割調整と分割・配当調整それぞれ1回、計2回の照会で各1004行を取得し全ページ終了を確認。再計算はその暗号化入力を再利用し、新規照会0回。[Alpaca日足の公式仕様](https://docs.alpaca.markets/us/reference/stockbars)。

2023/2024は既に条件作成に使った探索期間であり、未知期間の成績ではない。2025専用データは未開封。事後的な品質除外・年別母集団・株価調整の原書類未確認部分・実注文執行・税と為替の影響は引き続き限界。本番採用はしない。新たな購入シグナルは追加せず累積戦略案15を維持。
