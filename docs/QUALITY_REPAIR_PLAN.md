# 品質修正の事前条件と、モデル変更の採否基準

2026年9月10日。新しい取得・再計算結果を見る前に固定する。

ユーザーは、単なる成績向上ではなく目的に沿う合理的な改善なら条件変更を許可している。わたしたちは次の基準で判断し、根拠と不採用理由も保存する。

## 今回採用する修正

提供元の補正前・補正後データを照合する基準日を、評価期間末から取得日へ変更する。正式書類で確認済みのSMSI・GAME・KAPAの後の併合を照合に用いる。一方、出来高の判定は元データと判定日までの併合だけを使う。未来の併合を過去の特徴量へ混ぜない。

採用理由：同じ株数単位を比較するための訂正であり、保有増加や利益の結果を使って決める変更ではない。価格差の許容幅は広げない。書類と補正値がなお一致しない銘柄は保留を継続する。

## 今回の比較

- 元の54銘柄・主対象6銘柄を維持し、同じ取得データに旧・新の品質検査を適用する。以前の49銘柄の判定一致を別に調べ、新規復帰銘柄の追加による成績変化と混同しない。
- LSHの2026年1月5日について、同じニューヨーク日付の1日全体の日足・分足・約定を取得する。ページを取り切ったか、件数、正の出来高・数量があるか、通常約定があるかを記録する。数値0は欠損0埋めに変えない。
- Alpacaの公式説明は価格・出来高のいずれかが0なら足を生成しないとしている。日足の0を無取引と認定する根拠にはしない。公式説明との不一致、約定との矛盾、不完全取得は保留理由として保存する。分足合計による日足の自動置換はしない。
- 修正後の全群について、従来の四半期集計と月末までの集計を再計算する。結果は探索的な同一期の再評価で、独立した検証成功とは呼ばない。

## モデル条件を変えるための判断基準

1. 何を改善するのかを先に特定する。目的は低保有銘柄への機関流入候補の早期発見で、単に報告増加割合を最大にすることではない。
2. 成績に依存せず説明できる単位・日付・欠損処理の誤りは訂正する。旧版と同じ入力で比較し、不都合な結果も残す。
3. 経済的に筋が通っていても、予測力を変える閾値・期間・価格条件は仮説に留める。結果を見る前に条件を固定し、別の期間で比較する。複数の変更を同時に採用しない。
4. 最初の1か月は四半期末の答え合わせまで時間を残せるが、機関が月初だけ買う根拠ではない。1月の成績だけを理由に日々の監視を月初へ限定しない。
5. 反復は分割した買付けを拾う仮説として維持するが、買い手の特定や優位性が証明されたとは扱わない。値上がり条件の追加は、下落中の蓄積を落とす可能性も比較してから判断する。

次期検証では、四半期の最初の1か月と全期間を少数の事前固定比較にする。日々のシグナル自体は全期間保存し、最初の反復日から次の保有公開日までの時間も記録する。最新の保有一括資料の公開状況、当時の対象条件、銘柄識別と株数単位を確認してから実行する。今回の品質修正と次期の成績検証は別の記録にする。
