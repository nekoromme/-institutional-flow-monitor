# 次の価格損益比較：5〜6月、変更候補は一つ

2026年9月10日。[初回診断](STAGE4_RETURN_DIAGNOSTICS.md)を受けた事前計画。**5〜6月の新しい通知と損益を結合した成績はまだ計算していない。** 今回の候補を、初回診断で利益の大きかった保有期間や銘柄だけに合わせて変更しない。

## 比較対象と期間

- 対象は既存の固定54候補を追跡する。現在残る銘柄だけに置き換えない。低保有群は年初に固定した代理情報による6候補として併記し、5月時点の最新機関保有率と呼ばない。
- 通知対象は2026年5月1日〜6月30日。過去窓用に1月以降、結果追跡用に7月末までの価格を用意する。4月は初回の通知の20日結果に使ったため、新しい評価の通知期間から外す。4月までの既知の過去値を5月の特徴計算に使うことは許す。
- 銘柄変更・株式併合・上場廃止・価格欠損は当時の資料で確認する。特にCOMM・ASGNの旧コードのデータ不足は、無条件に新コードへ接続したり取引なしと扱ったりしない。不明の候補・通知日・取引を残す。
- 初回と同じ次の通常取引開始の価格参考値→10取引日目の終了を主評価、5・20日は補助。費用は各0.25％を主条件、0・0.5・1％もすべて報告。配当は価格損益と分ける。

これは期間を分けた追試で、未接触の最終試験ではない。最初の接続試験で一部銘柄の後の価格も取得している。候補をこの結果で変更した場合は、5〜6月を再び未検証期間と呼ばず、その後の期間と新しく生じる相場で確かめる。

## 固定する3モデル

| モデル | 購入候補となる条件 |
|---|---|
| A：単純比較 | 既存の異常出来高のみ |
| B：現行反復 | 既存の異常出来高＋直近5営業日に異常2日以上 |
| C：変更候補 | Bに加え、通知日の分割補正終値が5取引日前の終値より高い |

Cの5日間に必要な価格が欠ける場合は不明。株数・価格の単位は通知日までの正式な分割・併合で揃える。情報を使える仮定の時刻は初回と同じ、通知日のニューヨーク日付が終わった30分後とし、それより前の値だけを判定に使う。

60日の基準、出来高の境界、反復2／5、価格方向の5日と0、出口10日は固定する。1日・3日・7日への総当たり、銘柄別の最適値、ニュース点数、損切りと利確の同時追加は行わない。Cの理由は、出来高からは分からない価格方向を一つ加えて売りが強い場面の混入を減らす仮説。下落中の買い集めや反発を逃す場合も含めて比べる。

各モデルについて候補発生日から保有予定を独立して作り直す。Cが見送ると後の保有状態も変わるので、Bの成績表から負けた取引を削る計算では代用しない。同じモデル内の重複購入と、前の保有状態が不明の後の取引は初回と同じ扱い。

## 採用の判断と費用・執行の確認

主比較はC対B、Aも残す。同じ重みの取引平均に加え、中央値、勝率と勝ち負けの金額、最悪例、逆行幅、通知数、銘柄数、月別、銘柄を一つずつ除く影響を報告する。件数の減少を高精度と読み替えない。実際の資金制約のある運用利回りは別評価。

Cを次の本番候補検証へ進めるには、主条件の平均損益がプラスでBを改善し、片道0.5％でもプラスが残ることを確認する。中央値・損失側が悪化する場合、改善が少数銘柄・一月に依存する場合、事例不足や欠損のため判断できない場合は自動採用せず保留する。これは統計的有意性の保証ではない。今回の小さな対象群で得た改善を市場全体へ一般化しない。

同じ購入・売却日のSPYとの価格損益差を残す。規模・業種・売買の活発さを揃えた非通知群は未完成と表示し、その不足だけで大口の情報を捉えたとは結論しない。

価格の検証では、初回の固定標本で日足との開始価格不一致2件と終了直前の分足なし2件を先に点検し、引けの一括売買とその直前の価格を区別する。時刻と約定条件、気配・数量を調べ、注文サイズを伴う費用推定へ進む。都合の良い方の価格への差替えはしない。執行を確認できるまでは研究用の価格損益である。

配当補正については、初回で共通倍率の検査を通らなかった理由を提供元の方式と照合する。検査の仮定が誤っていれば損益の良否によらず訂正するが、現金配当や総合損益の確認を済ませたと扱わない。

価格評価上の改善が残れば、その後の期間と実際に新しく出る通知で継続検証する。別期間で消えるならCを棄却・保留し、失敗原因と試した案を記録する。毎回の利用者の追加設定を前提にせず、既存のデータ接続と再実行の仕組みを使う。
