# 別期間の実行方法と追加点検の固定

2026年9月10日。新しい5〜6月の通知後損益を取得・結合する前の記録。[比較条件](NEXT_RETURN_VALIDATION_PLAN.md)を変更せず、実装上の範囲を補足する。

- 価格は2025年12月15日〜2026年7月31日。12月分は旧1〜3月で価格方向を追加したモデルを、最初の購入予定から再計算するために使う。新しい通知は5〜6月だけ。4月・7月の通知を新たに評価しない。
- 旧1〜3月の出来高判定は既存版を使用。新5〜6月は各当日より前の60通常営業日の出来高から再計算し、価格方向は直前5取引日から当日まで6日の価格が揃う時のみ算出する。旧期間と新期間は別々に集計する。
- 同じ実行の既存取得と新規取得が重なる12月15日〜4月30日の価格・出来高を照合する。変更があれば該当銘柄を自動で更新せず不明にする。旧2モデルの全保有期間の集計が同じかも報告する。
- 既存の未解決例TGTX・2026年1月12日の開始、CNXC・1月15日の開始、SMSI・2月20日の終了、KAPA・3月13日の終了を固定標本にする。
- 開始例は09:30〜09:32未満、終了例は15:59〜16:01未満の約定と1分足を確認する。開始例は09:31、終了例は15:59を気配の参照時刻とし、その時点以前60秒以内の直近の正常な気配を使う。通信の追加ページを取り切れない場合、逆転した気配、数量ゼロ、古い気配は採点しない。
- 買いは売り手の提示価格、売りは買い手の提示価格を参考にし、売買価格差と日足価格からの差を別に示す。観測時刻の違いによる価格変動を手数料や売買価格差に混ぜない。数量は正であることのみ確認し、指定金額が全額約定したとは扱わない。この4例は市場全体の費用を推定する標本ではない。
- 配当補正の日足について、同じ日の四つの価格が共通倍率／共通差額で変わるかを点検する。いずれかに一致しただけで正式な現金配当の正解とせず、主な価格損益は変えない。

この追試は価格方向を加える一案の成否までを判断できる単位として実行する。成績を見た後に修正する場合は、新しい仮説・失敗理由・次の評価期間を別記する。
